# 2026-07-05

## 重构 GenerateNoiseTerrain.cs 地形生成系统

### 改动概要
- 为 `ApplyFractalNoiseToTerrain` 添加 `TerrainType` 枚举参数，支持 5 种地形预设：沙漠、高原、雨林、丘陵、盆地
- 新增 `TerrainPresetData` 结构体存放每种地形的完整参数（噪声、高度曲线、后处理、纹理映射、植被）
- 噪声算法从简单 2 层 PerlinNoise 升级为真正的 **fBm（分形布朗运动）**，支持可配置 octaves/lacunarity/persistence
- 将原来的"伪侵蚀"替换为 **地形类型专用的后处理管线**：
  - 沙漠 → `ApplyWindErosion()` 风蚀定向平滑
  - 高原 → `ApplyPlateauProcess()` 高度钳制+悬崖锐化
  - 雨林 → `ApplyHydraulicErosion()` 水力侵蚀山谷雕刻
  - 丘陵 → `ApplyGentleSmoothing()` 邻域平均平滑
  - 盆地 → `ApplyBasinDepression()` 径向凹陷+水力侵蚀
- 纹理分配改为预设驱动的动态图层映射（不再硬编码 layer 0-4）
- 树木生成加入坡度/高度约束，使用预设定义的树原型范围
- 新增 `_overridePreset` 开关保持旧 Inspector 参数向后兼容
- 修复 `Hills`/`Basin` 枚举显示名对调 bug
