- 在 `WeaponAttributeFactory.attributeConfigs` 中添加配置：`Percentage | OneHide, ModifierType.All`
- 在 `DamageData` 中添加 `ChargeHeatScale` 字段（默认1）、`GetAttr` 映射和 `SetChargeHeatScale` 方法

- 非蓄力武器 `WeaponChargeScale_D` 返回1，公式退化为 `heatPerShot * 1`，不影响现有行为

## 修复 SelectRoleWnd 切换角色后 GameEndWnd/ArmamentWnd 显示旧模型的 bug
- **根因**: `BridgeRoleManager.SelectRole()` 更新了 `Archive.lastSelectRole` 和玩家模型，但未同步更新 `roomManager.players[0].roleName`，而 `GameEndWnd`(第77行) 和 `ArmamentWnd`(第142行) 都通过 `roomManager.players[i].roleName` 加载模型，导致拿到的是切换前的旧值
- **修复**: 在 `SelectRole()` 末尾同步更新 `roomManager.players[roomManager.SelfIndex]` 的 `roleName`、`roleLevel`、`roleExp`、`weapons`、`Upgrades` 字段

## GlobalEventSub 新增 OnSelectRolePreview 事件
- 在 `GlobalEventSub` 中新增 `event Action<RoleData_SO> OnSelectRolePreview`，用于舰桥选人界面切换角色预览时通知其他模块
- `SelectRoleWnd.Refresh()` 中每次预览切换角色时调用 `GlobalEventSub.SelectRolePreview(data)`
- `BridgeWnd` 订阅 `OnSelectRolePreview`，在 `OnSelectRolePreview` 中更新 `selfName`、`selfIcon`、`selfLevel`、`selfExp`（参考 `SettingWnd.SetStateRoot` 的更新方式），通过 `resManager.LoadPrefab` 加载预制体获取 `BaseObject.ShowName` 和 `BaseObject.Portrait`

## 修复 TerrainMainUtils.GetHeights 越界崩溃
- **根因**: `GetHeights` 中 `heightmapRes = data.heightmapResolution - 1`（最大索引），但 `data.GetHeights(xBase, yBase, size, size)` 要求 `xBase + size <= data.heightmapResolution`（实际 resolution 值，如 513）。当 `xBase + size == heightmapResolution` 时越界，但原来的检查条件用的是 `> heightmapRes`（512），`== 513` 的情况漏过了
- **修复**: 检查条件改用 `data.heightmapResolution` 而非 `heightmapRes`，且从 `>` 改为 `>=`；越界时自动裁剪 size 防止崩溃
