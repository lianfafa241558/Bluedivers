# 2026-07-15

## DetectionModule 修复：敌人有目标但卡在 Idle 状态

### 问题
EnemyMobile 在 Idle 状态下，DetectionModule 已经有目标（Target.Actor 不为空），但敌人不切换到 Follow 状态，攻击它也不理。

### 根因
`DetectionModule.HandleTargetDetection()` 中 `OnDetect()` 的触发条件是 `!haveOldTarget && haveNewTarget`（目标从无到有）。当敌人短暂丢失视线后重新看见你时，因为 `Target.Actor` 引用一直存在（未超过 `KnownTargetTimeout`），`haveOldTarget` 始终为 true，`OnDetect()` 不会被触发，状态机卡在 Idle。

### 修复
在 `DetectionModule.cs` 中：
1. 新增 `m_WasSeeingTargetLastFrame` 字段记录上一帧是否可见
2. 修改 `OnDetect()` 触发条件：增加 `(haveNewTarget && !m_WasSeeingTargetLastFrame && IsSeeingTarget)` 分支，当旧目标从不可见变为可见时也触发重新发现

## 修复：已死亡单位仍活动且无法被击杀

### 问题
有时单位剩余生命值为 0、actorState=Dead，但还在活动且怎么攻击都不会死亡。

### 根因
1. **`Health.TakeDamage` 未检查 `m_IsDead`**：入口只检查了 `Invincible`，死亡后仍能接收伤害，`HandleDamage` 和 `AddAboGauge` 在死亡后继续执行，异常状态 tick 持续触发。
2. **`EnemyMobile.UpdateAiStateTransitions` 未守卫 `AIState.Death`**：死亡后状态切换逻辑仍在运行，若外部回调触发状态切换可能意外覆盖死亡状态。
3. **`EnemyMobile.UpdateCurrentAiState` 未守卫 `AIState.Death`**：死亡后移动/攻击/异常状态（Toxicity/Terror/Hacker）逻辑仍可能执行。

### 修复
- `Health.TakeDamage`：入口增加 `|| m_IsDead` 检查
- `EnemyMobile.UpdateAiStateTransitions`：增加 `if (AiState == AIState.Death) return;`
- `EnemyMobile.UpdateCurrentAiState`：增加 `if (AiState == AIState.Death) return;`
