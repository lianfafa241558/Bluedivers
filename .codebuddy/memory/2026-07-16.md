# 2026-07-16

## SelectRoleWnd.cs tipRoot 多分辨率适配修复
- **问题**：`ShowTip`(L515) 和 `MoveTip`(L563) 中用 `tipRoot.position = new(tipRoot.position.x, Input.mousePosition.y - 50, transform.position.z)` 直接设置世界坐标，在 1920 分辨率下正常，但 2560 分辨率下因 Canvas Scaler 缩放导致位置不对。
- **修复**：提取 `UpdateTipPosition()` 方法，使用 `RectTransformUtility.ScreenPointToLocalPointInRectangle` 将 `Input.mousePosition` 转换为 Canvas 本地坐标，然后设置 `_tipRect.anchoredPosition`。缓存 `_tipRect` 和 `_canvasRect` 引用避免重复获取。
- **影响文件**：`Assets/Scripts/04UI/SelectRoleWnd.cs`

## MovieWnd.cs 黑边多分辨率适配修复
- **问题**：`ShowWnd` 中用 `(size.y - (size.x / 2.2f)) / 2` 计算上下黑边高度，`size` 来自 `Tool.ScreenSize2D`（实际屏幕像素），但 `sizeDelta` 是 Canvas 空间的值，在非 1920x1080 分辨率下因 Canvas Scaler 缩放导致黑边高度不正确。
- **修复**：改用 `Constants.CanvasWidth/CanvasHeight`（1920x1080）作为基准计算黑边高度，直接得出 Canvas 空间下的正确值。提取 `AdaptBlackBars()` 方法，提取 `MovieAspectRatio` 和 `MinBlackBarHeight` 常量。
- **影响文件**：`Assets/Scripts/04UI/MovieWnd.cs`
