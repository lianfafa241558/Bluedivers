## PlayerController 第一/第三人称切换功能
- 新增按 T 键切换第一/第三人称视角
- 修改文件：
  - `PlayerInputHandler.cs`：新增 `GetToggleViewDown()` 方法，用 `Input.GetKeyDown(KeyCode.T)` 检测 T 键
  - `PlayerController.cs`：新增 `partial` 关键字，`Foldout("第三人称")` 参数，`IsThirdPerson` 属性
  - `PlayerController_ThirdPerson.cs`（新建 partial）：包含所有第三人称逻辑

### 参数设计
- `_thirdPersonCameraPoint`（Transform）：控制第三人称相机相对于角色的偏移位置（替代之前 distance+height 两个 float），直接在角色下挂空 GameObject 调整
- `_thirdPersonSmoothSpeed`（1-20）：位置和旋转跟随平滑度
- `_thirdPersonOcclusionLayers`：遮挡检测层
- `_thirdPersonMinDistance`（0.5-3m）：遮挡时最小距离
- `IsThirdPerson`（DisplayField）：当前视角状态

### 第三人称逻辑（PlayerController_ThirdPerson.cs）
- `HandleToggleView()`：T键切换，同时控制头部模型（MainCameraIgnore层）和 WeaponCamera 的显示/隐藏
- `HandleRotationThirdPerson()`：
  - 有移动输入 → 角色朝向移动方向（Slerp 平滑）
  - 无移动输入 → 角色跟随鼠标水平旋转（相机注视方向）
  - 垂直角度始终跟随鼠标输入
- `GetInputMoveThirdPerson()`：移动输入相对于角色朝向
- `HandleThirdPersonCamera()`：
  - 相机位置 = transform.position + transform.rotation * _thirdPersonCameraPoint.localPosition
  - 射线遮挡检测 + SmoothDamp 平滑位置跟随
  - 相机注视前方（限制俯仰范围）
  - 每帧计算 ScreenCenterTargetPoint

### 第三人称瞄准 FOV 缩放
- PlayerWeaponsManager.UpdateWeaponAiming：第三人称瞄准时 `zoomRatio = 1 - (1 - AimZoomRatio) * 0.5`
- 例如 AimZoomRatio=0.4 → 第三人称实际 zoomRatio=0.7（视野更大）

### 切回第一人称瞬间跳转
- PlayerController.LateUpdate 增加 `_wasThirdPersonLastFrame` 检测
- 刚从第三人称切回第一人称时，瞬间设置 PlayerCamera 位置到 CameraBasePoint，避免看到头部消失

### 第三人称武器瞄准
- `WeaponPlayerController` 新增 `ThirdPersonAimTarget` 属性（由 PlayerWeaponsManager 注入）
- `WeaponPlayerController.GetShotDirectionWithinSpread` 重写：当 `ThirdPersonAimTarget != default` 时，子弹从枪口指向目标点
- `PlayerWeaponsManager.LateUpdate` 新增 `UpdateWeaponThirdPersonAim()`：第三人称时遍历所有武器槽位注入 `ScreenCenterTargetPoint`，第一人称时清零

## Furniture_NPCChat 自动搭话系统
- 新增自动搭话功能，NPC 不再需要玩家主动交互才说话
- 新增配置参数：
  - `_autoChatDistance`（默认5m）：玩家进入此范围自动触发搭话
  - `_autoChatCooldown`（默认10s）：两次自动搭话最小间隔
  - `_enableAutoChat`：开关自动搭话
- 自动搭话逻辑（TryAutoChat）：每帧检测玩家距离，满足条件时触发 DoChat()
- DoChat()：播放语音、暂停游荡、面向玩家、等待语音结束后恢复游荡
- 手动交互（Operate）仍然保留，和自动搭话共用 DoChat()
- 通过 Tag="Player" 查找玩家 Transform 并缓存，避免每帧 Find
