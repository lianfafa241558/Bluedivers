## TerrainUtils.cs + AdditionTerrain 高度修复（最终方案）
- 根因1：`TerrainUtils.cs` 第16行 `WSToHeight` = `SampleHeight(pos) + GetPosition().y`，而 SampleHeight 已含 transform.y → 双倍偏移
- 根因2：AdditionTerrain 直接用源地形的绝对世界高度覆盖主地形，当源地形高度图平坦且世界 Y=0 时核心区沉到 0
- 修复1：`TerrainUtils.cs` WSToHeight 移除 `+ GetPosition().y`，返回 `SampleHeight(pos)`
- 修复2：`AdditionTerrain` 改用源地形**中心点高度**为基准：`sourceRelativeH = sourceWorldH - sourceCenterWorldH`，`sourceHeight = (targetHeight + sourceRelativeH) / terrainHeight`。核心区锚定到 targetHeight，周围保留相对形状
- ModifyTerrain.Modify() 末尾 Raycast 重新贴地逻辑已移除

## Infrared.cs 线段抽搐修复
- 根因：代码使用世界坐标 SetPosition，但未显式设置 `line.useWorldSpace = true`。若 LineRenderer 的 useWorldSpace 被意外设为 false，世界坐标被当本地坐标解释，物体移动时线段剧烈跳动
- 修复：在 Start() 中添加 `line.useWorldSpace = true` 显式强制

## SubtitleNPC.cs 添加距离淡出效果

## AIInputUnitController.cs Turret.Rotate Idle 状态下疯狂绕 X 轴旋转修复
- **根因**：`Rotate(float angle)` 中每帧都乘以 `chassisOffset`，但 `chassisRotation` 在 Init/Synchro/Look 中已包含该偏移，导致 chassisOffset 每帧累积叠加。若底盘初始有 X 轴倾斜，X 轴分量以 ~fps×offsetX°/s 的速度疯狂旋转
- **修复**：移除 `Rotate` 中所有多余的 `* chassisOffset`，直接 `nextRotation = chassisRotation * Quaternion.AngleAxis(angle, Vector3.up)` 后赋给 chassis.rotation。同时修正 `limitRotation` 检测中的 `chassisForwardXZ` 计算，用 `nextRotation * Vector3.forward` 替代 `chassisDir * chassisOffset * Vector3.forward`

## VehicleController 第三人称进入载具 Camera.main 消失修复（v2：标志位方案）
- **根因**：`VehicleController.SetOwener` 中 `comp.enabled = false` 触发 `PlayerController.OnDisable`，后者在第三人称模式下调用 `PlayerCamera.gameObject.SetActive(false)` 关闭相机，导致 `Camera.main` 返回 null。之前 v1 用后置 `SetActive(true)` 修复，但瞄准等情况下仍可能失效（`RestoreCameraParent` 恢复的父级挂玩家层级下，之后 `owner.transform.parent` 改挂载具时相机 activeInHierarchy 可能变 false）
- **v2 修复**：从源头阻止。在 `PlayerController` 新增 `[HideInInspector] public bool SkipCameraDeactivateOnDisable` 标志位，`OnDisable` 中检查此标志，为 true 时跳过 `SetActive(false)`。`VehicleController.SetOwener` 在 `comp.enabled = false` 前设为 true，之后立即复位。无论瞄准/非瞄准、任何第三人称状态都能正确处理
- **载具B修复**：`EmplacementController` 有同样 bug，已同步修复。同时 `VehicleController.LateUpdate` / `EmplacementController.LateUpdate` 增加防御：如果相机意外 inactive 则每帧自动检查并 `SetActive(true)` 恢复
- **退出载具时武器相机误激活修复**：`VehicleController` / `EmplacementController` 退出时无条件 `WeaponCamera.enabled = true`，第三人称不需要武器相机。修复：新增 `_wasThirdPersonOnEnter` 字段在进入时记录视角状态，退出时仅在第一人称下才启用武器相机
