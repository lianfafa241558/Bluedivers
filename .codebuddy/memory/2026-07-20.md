## 修复 SettingWnd 关闭时恢复错误的 WindowState（最终方案：WndManager.OnWindowStateSet）

- **问题**：SettingWnd 打开时 oldStste=Game，ArmamentWnd 随后打开（WindowState=UI 但已是UI），SettingWnd 关闭时错误恢复为 Game。
- **最终方案**：在 `WndManager.WindowState` setter 中加 `OnWindowStateSet` 事件（每次 set 都触发，不管值是否相同）。SettingWnd 监听此事件，用已有的 `selfChangeState` 标志区分自己/别人，动态更新 oldStste。
- **优势**：零计数、ArmamentWnd 零改动、Window 基类零改动。只需 WndManager 加事件 + SettingWnd 换监听。
- **改动文件**：
  - `WndManager.cs`：setter 中先设值再无条件触发 `OnWindowStateSet`，`OnWindowStateChange` 仅 oldState!=value 时触发
  - `SettingWnd.cs`：`FirstShowWnd` 改为订阅 `OnWindowStateSet`（替换 `OnWindowStateChange`），handler 逻辑不变（selfChangeState 跳过 + oldStste=state）
