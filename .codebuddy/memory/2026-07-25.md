# 2026-07-25

## GenerateKeyCodeItems.cs
- 新增 `Assets/Editor/GenerateKeyCodeItems.cs`，提供菜单 `Tools/Generate KeyCode Items`
- 功能：以 Hierarchy 中选中的 GameObject 为模板，为每个键盘 KeyCode 创建一个副本（排除 None/Mouse/Joystick）
- 每个副本：命名为 KeyCode 名称，`KeyCodeItem.key` 设为对应 KeyCode，第一个子物体的 `TextMeshProUGUI.text` 设为 KeyCode 名称，放置于模板同父级下
- 使用 `Undo.RegisterCreatedObjectUndo` 支持撤销
- 更新：模板为预制体实例时，改用 `PrefabUtility.InstantiatePrefab(prefabAsset, parent)` 保持预制体链接（而非 `Object.Instantiate` 产生非链接副本）
