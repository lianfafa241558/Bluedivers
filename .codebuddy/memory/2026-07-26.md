  - 加载后重置所有 `lastTime` 为 `Mathf.Infinity`（运行时状态不持久化）

- `InputItem` 中的 `event Action` 字段无法序列化（Unity 序列化器自动跳过），加载后 `base.Awake()` 通过 `waitBind` 机制重新绑定事件，无影响

## FpsHelper.cs Teleport — 修复"怎么闪都返回原地"bug
- **根因**：`Teleport()` 先 `controller.transform.position = targetPosition`，再调 `PreventUnderground`。后者从 `targetPosition + halfHeight + radius` 向下 SphereCast，但 CharacterController 已被移动，SphereCast 起始球体与其胶囊碰撞体顶部相切，立即命中自身，`hit.distance ≈ 0` → `groundDistance < 0` → `correctedY = 头顶 + halfHeight + skinWidth`，角色被抬到半空。下一帧 GroundCheck 又 `Move(down * distance)` 落下，表现"返回原地"。
- **修复**：先 `PreventUnderground(controller, targetPosition)` 检测，再 `controller.transform.position = finalPosition + 0.2f * up`，避免自身 collider 干扰 SphereCast。

## VehicleWeaponsManager.cs — 修复载具激光武器 NRE（Owner 为空）
- **根因**：载具武器（`m_WeaponSlots`）从未设置 `Owner`，`ProjectileLaser._OnShoot` 中 `Owner.GetComponentsInChildren<Collider>()` NRE
- **修复**：
  - `IDrivable` 接口新增 `GameObject CurrentOwner { get; }` 属性
  - `VehicleController` 和 `EmplacementController` 显式实现，暴露私有 `_owner`/`owner`
  - `VehicleWeaponsManager` 在 `OnSetOwner` 时通过 `m_Controller.CurrentOwner` 获取真实驾驶员，同步给所有武器的 `Owner`；`AddWeapon` 时也自动设置
- 第三人称分支不再用 `Physics.OverlapSphere`，改为直接遍历 `Furniture_Attached.list.Values`
- 排除自己身上的家具：`furn.gameObject.transform.IsChildOf(transform)` 跳过
- 空值保护：`furn == null || furn.gameObject == null` 时 `continue`
- 距离比较使用 `furn.gameObject.transform.position` 而非 collider.position

## BaseSelfMoveableController.cs — 修复高台阶上下抖动
- **根因**：上周修复陡坡卡死时新增的 `_isOnSteepSlope` 标志在 `GroundCheck()` 中会把近垂直的台阶/墙面也误判为陡坡，导致 `HandleCharacterMovement()` 把位移投影到坡面，与 `CharacterController` 的台阶攀爬冲突，角色在较高台阶处反复上下抖动上不去。
- **修复**：在 `GroundCheck()` 的陡坡分支增加法线向上分量阈值 `Vector3.Dot(hit.normal, transform.up) > 0.3f`，只有真正陡峭的斜坡才设置 `_isOnSteepSlope`，台阶和墙面不再触发陡坡滑动。
