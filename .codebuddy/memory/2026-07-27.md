# 2026-07-27

## SubtitleWnd 第三人称载具 UI 抖动修复

### 尝试过的方案（均失败）
1. **Update → LateUpdate**：未解决，相机也在 LateUpdate 中用 SmoothDamp
2. **屏幕坐标 SmoothDamp**：移动视角时 UI 拖拽滑动，体验差
3. **Camera.onPreCull**：UI 完全不显示

### 最终根因与修复
- **根因**：`Furniture_Attached.CenterPos` 使用 `collider.bounds.center`。`bounds` 每帧重新计算 AABB 包围盒，CharacterController 移动时包围盒中心有微小波动，导致 `WorldToScreenPoint` 结果左右晃动
- **验证**：换成 `nearest.transform.position` 后抖动消失
- **最终修复**：
  - `Furniture_Attached.cs`：`collider.bounds.center` → `transform.TransformPoint(collider.center)`。`collider.center` 是本地常量偏移，不重新计算 AABB，`TransformPoint` 转到世界坐标，同样指向碰撞器中心但完全稳定
  - `SubtitleWnd.cs`：保留 `nearest.CenterPos` + `Mathf.Round` 屏幕坐标取整（消除 SmoothDamp 相机导致的亚像素跳动）
