## SoundGroup_SO 预览播放
- 新增 `Assets/Editor/SoundGroup_SOEditor.cs`（CustomEditor）：Inspector 顶部加「预览播放」按钮 + 「循环试听」按钮。
- **关键坑：Edit Mode 下场景 AudioSource.Play() 不会真正出声**（无运行的音频引擎/AudioListener 渲染）。必须先反射调用 Unity 内部 `UnityEditor.AudioUtil` 预览机制。
- **Unity 2022.3 的 AudioUtil API 注意**：预览方法是 **`PlayPreviewClip(AudioClip, int startSample=0, bool loop=false)`**（不是 `PlayClip`！旧版本/网上资料是 PlayClip，2022 已改名）。配套方法：`StopAllPreviewClips()`、`IsPreviewClipPlaying()`、`LoopPreviewClip(bool)`。`AudioUtil` 类是 `internal`，但方法是 `public static`，反射用 `BindingFlags.Public | BindingFlags.Static` 即可（`typeof(Editor).Assembly.GetType("UnityEditor.AudioUtil")`）。
- 预览：`sg.Get(Vector3.zero)` 取 RuntimeSoundData（支持有序/随机），仅取 `.Clip` 用于预览；循环用 `PlayClip(clip,0,loop)`。volume/pitch/space 等属性不被 AudioUtil 采用（官方预览机制本身不带这些参数），只保证能听到。
- 注意：`SoundGroup_SO.clips` 是 private 字段，Editor 内用 `serializedObject.FindProperty("clips").arraySize` 取数量，不能直接访问。

## AIInputUnitController.Turret 炮台重构
- 新增 `TurretType` 枚举（Full / SelfBody）：SelfBody 为"自体炮塔"，无武器、无垂直旋转，仅控制底盘水平旋转。实现上通过无 weapon（跳过重力补偿）、无 barrel（跳过俯仰）天然支持。
- 新增 `verticalLimitRotation`（垂直/俯仰限制角度），配合原有 `limitRotation`（水平）双轴限制。`GetLimitedVerticalDirection()` 将炮管俯仰角钳制到相对水平面的 [-maxAngle,+maxAngle]。
- 空引用防护：`firePoint` 改 null-safe（`weapon ? weapon.WeaponMuzzle : null`）；`Init` 缺底盘/发射点告警；`Look` 内底盘正上/下方时水平方向兜底为 forward 防 LookRotation 抛异常；`Rotate` 缺底盘 return。新增 `implicit operator bool`。
- `Rotate` 限角回弹时改为 `Quaternion.LookRotation(GetLimitedDirection(...)) * chassisOffset` 直接贴边界，防临界抖动。
- 性能：控制器 `Start`/`UpdateTurretAiming`/`CalculationAimTargrt` 的 `ForEach` 闭包改 `for` 循环。
- `OnDrawGizmosSelected`（#if UNITY_EDITOR）：绘制底盘黄色朝向、炮管红色朝向、水平限制青色扇形（DrawArcSector）、垂直限制橙色上下射线、武器发射点品红朝向。
- `TurretDrawer.cs` 同步更新：新增"炮塔类型"下拉与"垂直限制角度"滑条，布局扩至 13 行。
- `TurretDrawer.cs` 按炮塔类型动态显示：SelfBody 只显示 底盘/类型/水平限制/瞄准锐度（7 行），隐藏炮管/武器/垂直限制/瞄准时间/开火延迟/偏移/偏差/dot。
- `aimSharpness` 语义从"Slerp 衰减插值系数"改为"**匀速转向转速系数**"：`1=180°/秒`（`0.5=90°/秒`），`Look()` 用 `Quaternion.RotateTowards(from,to, aimSharpness*180*Time.deltaTime)`。默认值从 5 改为 1。
- 新增 `Editor/TurretSharpnessGlobalTool.cs`：菜单 `Tools/Turret/批量换算瞄准锐度（×90，封顶180）`，遍历 Assets 下所有继承 `AIInputUnitController` 组件的预制体，对 `turrets[].aimSharpness` 执行换算：**值 <10 则 ×90，封顶 180**（旧 Slerp 系数 5 → min(450,180)=180）。执行前有确认对话框。
- **水平限制基准修正**：`limitRotation` 的水平限制基准从"根物体 forward"改为"**底盘初始朝向**（chassisStartRotation 的 forward 水平投影）"。`Look()` 逻辑与 `DrawGizmosSelected` 显示同步。这样多炮塔单位（如坦克左右机枪，各自底盘朝向不同）每把炮塔以自身底座朝向为中心限制 ±limitRotation，符合直觉。`Rotate()` 巡逻原本就用 chassisStartRotation，现已统一。
- **DrawGizmosSelected 基准再修正**：编辑器模式下 `chassisStartRotation` 未初始化（Init 仅在运行时调用，恒为 identity），导致所有炮塔扇形都以世界 +Z 为基准而偏到一侧。改用**底盘当前朝向** `chassis.rotation` 的水平投影作基准（编辑态底盘处于初始姿态，即正确朝向）。
- **SelfBody 自体炮塔导致 NRE 修复**：`EnemyController.TryAtack`/`TryStop` 对 `weapon==null` 加防护（`if(!weapon) return`），覆盖 EnemyMobile/EnemyTurret/SpecUnitKei 等所有调用方。`EnemyMobile` 攻击分支改为 `item.weapon && item.IsLockTarget(...)`。SimpleTurret/GuardDog 自带 `if(!turret.weapon) return` 本就安全。
- **炮塔自动巡逻旋转（选择性）**：`Turret` 新增 `autoRotateSpeed`（°/秒，>0 才启用自动巡逻）和 `AutoRotate(deltaTime)`（内部调 Rotate+Synchro，速度<=0 自动跳过）+ `HasAutoRotate`。`EnemyMobile` 在 Idle/Patrol 状态调用 `UpdateAutoRotate()`（遍历 turrets 调 AutoRotate），实现只让设置了 autoRotateSpeed 的炮塔（如左右机枪）巡逻转，其他炮塔不动。`TurretDrawer` 新增"自动巡逻速度"显示，SelfBody/Full 行数各 +1（7→8，13→14）。
- `EnemyTurret.cs` 统一改 `AutoRotate()`：删除 `RotationSpeed` 字段，Idle 状态遍历 `turrets[i].AutoRotate(Time.deltaTime)`。迁移说明：老预制体的 `RotationSpeed` 值需手动配到每个 Turret 的 `autoRotateSpeed` 上（用户自行配置）。
- **炮塔独立索敌**：`Turret` 新增 `CanReach(targetPos)`。`EnemyMobile.UpdateTurretAiming`(LateUpdate) 重构：战斗状态(Follow/Attack)且目标可达 → `Aiming()`，否则（非战斗 或 目标不可达）→ `AutoRotate()` 巡逻。`EnemyMobile` 的 Idle/Patrol 里 `UpdateAutoRotate()` 调用移除（统一到 LateUpdate，避免双重旋转）。`EnemyTurret.UpdateTurretAiming` 同样改为 Attack 状态独立索敌。实现"每炮塔独立索敌，够不到/无目标就巡逻转"。

- **Rotate 跳变修复**：自动巡逻到限制角（如90°）时原用 `LookRotation(GetLimitedDirection(...))*chassisOffset` 重建旋转，导致瞬间"回正到0°"再反向。改为 `SignedAngle` 计算相对起始朝向的带符号偏角，超限时 `rotateDir=-rotateDir` + `AngleAxis(clamped-curAngle)*nextRotation` 增量回退贴边，实现平滑反向往复摆动。

- **角度不够的机枪攻击状态抽搐修复**：根因是 `AimTargrt()` 用 `CalculationAimTargrt` 对**所有**炮塔调 `Look()`（Update 阶段往目标转），而 LateUpdate 里 `CanAim=false` 的炮塔又走 `AutoRotate`（往巡逻方向转），两阶段冲突导致左右抽搐。修复：`EnemyMobile`/`EnemyTurret` 的 `AimTargrt()` 改为只对 `CanAim` 为 true 的炮塔调 `Look()`，够不到的炮塔保持巡逻，不再被 Look 干扰。
- **「瞄不到就巡逻」机制已回退**：效果不好，用户决定去掉。`EnemyMobile`/`EnemyTurret` 的 `UpdateTurretAiming`/`AimTargrt` 恢复为对**所有**炮塔 `Aiming`/`Look`（原行为）。`Turret.CanAim` 方法已删除（死代码）。保留的独立索敌相关仅剩 `autoRotateSpeed` + `AutoRotate`（Idle/Patrol 巡逻）。
- **EnemyMobile 常态巡逻恢复**：回退「瞄不到就巡逻」时误删了 Idle/Patrol 里的 `UpdateAutoRotate()` 调用和方法，导致常态不旋转。已恢复 `UpdateAutoRotate()` 方法并在 Idle/Patrol 分支调用。`EnemyTurret` 的 Idle 巡逻本就内联 `AutoRotate`，不受影响。
- **水平限制基准改为可配置跟随物体**：原用 `chassisStartRotation`（底盘初始世界朝向，固定不随坦克转向，表现为"绝对角度"）。用户需求：根物体 forward = 坦克朝向，但主炮挂在炮塔层级下会跟着转，故需每炮塔可单独指定跟随哪个物体。新增 `Turret.limitFollow`（Transform，可空，留空=根物体）。新增 `GetLimitBaseForward()` = `limitFollow ?? root` 的 forward 水平投影。`Look()`/`Rotate()`/`DrawGizmosSelected` 三处基准统一用它。删除已无用的 `chassisStartRotation`。`TurretDrawer` 新增"水平限制跟随"字段，SelfBody/Full 行数各 +1（8→9，14→15）。

- **炮塔最小攻击距离**：`Turret` 新增 `minAttackRange`（目标距离炮塔小于该值不开火，0=不限）+ `CanFireAt(targetPos)`（基于底盘位置判定距离 >= minAttackRange）。所有开火调用点已接入：EnemyMobile/EnemyTurret/SpecUnitKei 攻击分支加 `item.CanFireAt` 判断；SimpleTurret/GuardDog 自己的 TryAtack 内加判断。EnemyMobile 毒性无目标乱开火分支不涉及距离，未改。`TurretDrawer` Full 区新增"最小攻击距离"独立行，Full 行数 14/13→15/14。
- **aimSharpness 语义改为直接=度/秒**：原语义 `aimSharpness×180=°/秒`，导致设30=5400°/秒瞬间转向。用户确认改为**直接=°/秒**（设30=30°/秒）。`Look()` 中 `maxDegreesDelta = aimSharpness * Time.deltaTime`（去掉×180），默认值从1改为60，Tooltip 更新。注意 `TurretSharpnessGlobalTool` 的×90封顶180换算规则基于旧语义，已不适用。
- **EnemyTurret 预判与转向解耦**：`PreJudgmentDirection` 原来复用 `aimSharpness` 作预判放大系数，语义改变后（30/60大数值）会过度预判。新增独立字段 `EnemyTurret.PreJudgmentFactor`（预判强度，默认1），`aimSharpness` 只负责转向速度。预判方向改为 `tar + PreJudgmentFactor * dx`。
- **移除 aimBlendTime**：用户认为只需要 aimSharpness（°/秒）控制转向，不再需要"发现目标后的过渡平滑"。`Turret.Aiming()` 简化为直接应用 `Look()` 中用 aimSharpness 渐进算出的 `chassisRotation`/`barrelRotation`。删除 `aimBlendTime` 字段及 Drawer 显示。Full 区"瞄准时间+开火延迟"行改为"开火延迟+最小攻击距离"行，Full 行数 15/14→14/13。转向现在完全由 aimSharpness 决定。
- **水平限制方向乱跳修复**：1) `GetLimitedDirection` 原用 `Vector3.Cross(from,to)` 求旋转轴，目标与基准接近反向时叉积退化为零轴 → NaN → 方向乱跳（如主炮指向 back、机枪转180°）。改为 `SignedAngle(from,to,up)` + clamp 到 ±maxAngle + `AngleAxis(clamped,up)*from`。2) `Look()` 中 `chassisDir` 在目标正上/下方时接近零向量，原兜底 `Vector3.forward` 会水平乱跳，改为保持底盘当前水平朝向 `chassisRotation` 的前向投影。这两项修复目标：玩家钻到坦克正下方时机枪不再水平旋转180°，主炮限制基准稳定。
- **子炮塔转向速度约束（重要坑）**：人型机甲中主炮是 spine0（腰部底座）的子物体，主炮用绝对世界瞄准+固定 chassisOffset，与 spine0 实时旋转耦合。若主炮转向速度 < spine0 转向速度，会被父级旋转拖乱导致指向错误（指向 back）；主炮速度 ≥ 底座速度则正常（实测 spine0=10、主炮=30 正常，spine0=30、主炮=10 异常）。约束已写入 `aimSharpness`/`limitFollow` 的 Tooltip 和 `Look()` 代码注释，防止遗忘。
