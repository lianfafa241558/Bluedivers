## GuideController NavMesh 路径寻路
- 修复：移动被障碍物挡住。原因：原 `MoveRoutine` 直接朝目标点直线移动，不绕障。
- 解决：`MoveTo` 中用 `NavMesh.CalculatePath(from, to, NavMesh.AllAreas, path)` 同步计算路径（y 清零，参考 `Tool.NavDis` 写法）。路径 `PathComplete` 且有拐点时存 `_pathCorners = path.corners`；否则退化为 `new[]{ to }` 直线。
- 新增字段 `Vector3[] _pathCorners` + `int _pathIndex`。`MoveRoutine` 沿拐点依次移动：先 `FaceTarget(waypoint)` 面向当前拐点，水平距离≤`_arriveDistance` 时 `_pathIndex++` 前进到下一拐点；拐点遍历完即到达。用 CharacterController `TryMove` 逐帧驱动位移。
- `MoveRoutine` 结束清空 `_pathCorners`/`_pathIndex`。

## GuideController 到达后对齐朝向 + 停止距离
- 停止距离：新增 `[SerializeField] _stopDistance`（最终停止距离，默认1.5）。`MoveRoutine` 中判断当前拐点是否最终目标点（`_pathIndex >= _pathCorners.Length-1`），最终点用 `_stopDistance` 判定到达（避免与提示物重叠），中间拐点用 `_arriveDistance`。
- 到达后对齐朝向：`MoveRoutine` 改为接收 `Transform target`（`MoveTo` 传 `target.transform`），到达 break 后调用 `AlignRotationTo(target)` 把角色旋转对齐到目标物体朝向（仅绕 Y 轴，forward 水平投影，处理 forward 垂直退化）。
- `OnArrived` 事件参数改为传 `targetPos`（Vector3）。新增私有方法 `AlignRotationTo(Transform)`。

## GuideController 到达后平滑转向
- 到达后的朝向对齐从瞬间改为平滑过渡：`MoveRoutine` 到达 break 后 `yield return StartCoroutine(RotateToRoutine(target))`，旋转完成后再触发 `OnArrived`。
- 新增 `RotateToRoutine(Transform)`：用 `Quaternion.RotateTowards(transform.rotation, targetRotation, _rotateSpeed * Time.deltaTime)` 平滑旋转（_rotateSpeed 为度/秒）。`Quaternion.RotateTowards` 夹角小于步长时直接返回目标，循环能正常退出。
- 新增 `GetTargetRotation(Transform)`：计算目标物体朝向旋转（forward 投影水平面，仅绕 Y 轴，forward 朝上/朝下退化时返回当前旋转）。删除原瞬间对齐的 `AlignRotationTo`。

## GuideController 被障碍阻挡时绕行
- 修复"前面阻挡就原地停下"：原卡住检测用"水平位移<0.01f"判断，但 CharacterController.TryMove 撞墙时因碰撞解算产生微小抖动（>0.01f），导致卡住检测误判为"在移动"，stuckTimer 一直被重置永不触发 → 原地停下。
- 修复：卡住检测改为基于"到当前拐点的水平距离持续未减少 0.05f 以上"（`horizontalDistance > lastWaypointDistance - 0.05f`），不受抖动影响。
- 卡住 0.5s 后 `yield return StartCoroutine(DetourRoutine(waypoint))` 侧向绕行。
- `DetourRoutine`：计算朝拐点方向 dir 和右向量，`DetectFreeSide(right)`（Physics.CapsuleCast 探测左右侧）选可通行侧，朝该侧移动最多 1.5s；若到拐点距离减少>0.2f 则提前结束（绕过成功）。
- `DetectFreeSide`：用 `_controller.center/height/radius` 构造胶囊，`Physics.CapsuleCast(bottom,top,radius,sideDir,out _, _moveSpeed*dt+radius, DefaultRaycastLayers, IgnoreTrigger)` 探测侧向是否可通行。
- 注意：NavMesh 是静态烘焙的，动态玩家障碍不影响路径；此侧向绕行用于绕过运行时动态障碍。绕行失败会反复"卡住0.5s→绕行1.5s"循环（玩家让开即通过），属合理动态避障表现。

## GuideController 绕行方向改进（障碍移除后不恢复）
- 用户反馈："前面阻挡停一下后，即使玩家走开角色也不动"。
- 根因分析：原绕行用一次性 `DetectFreeSide` 固定选一个侧向（优先右），若角色贴拐角/探测误判方向，`TryMove` 持续被挡位移0，绕行1.5s白费→主循环卡0.5s→再绕行同一错误方向→无限原地打转不前进（即使障碍移除）。
- 修复1：绕行方向每 0.3s 用 `DetectFreeSide` 动态重探测左右侧，可通行侧变化时切换方向，避免固定方向卡死。
- 修复2：绕行移动方向改为混合方向 `(sideDir * 0.7f + dir * 0.3f).normalized`（侧向为主+前进分量），保证绕行时持续朝拐点推进，障碍移除后能自然恢复前进。
- 若仍不恢复可加 Debug.Log 输出卡住次数/方向辅助定位。

## GuideController 小坡跳跃（NavMesh 路径上坡）
- 用户反馈：横向绕行能绕过，但小坡不跳跃，卡在坡前左右横移。
- 原因：NavMesh 路径拐点跨过小坡，但角色用 CharacterController 水平移动无垂直上升能力，被坡挡住位移0 → 卡住检测→横向绕行→仍上不去→左右横移死循环。
- 修复：
  1. 新增 `_verticalVelocity` 字段统一管理垂直速度。
  2. 重构 `GravityRoutine`：落地时轻微下压(-2)，空中 `_verticalVelocity -= _gravity*dt`，每帧 `TryMove(Vector3.up * _verticalVelocity * dt)` 应用垂直位移（替代原简单下压）。
  3. 新增 `CanStepUp(forwardDir)`：底部 Raycast（脚底+0.1m）前方探测台阶命中 + 顶部 Raycast（脚底+_maxStepHeight）前方无障碍 → 判定可跳跃越过的小坡。
  4. 新增 `Jump()`：`_verticalVelocity = _jumpForce`。
  5. `MoveRoutine` 卡住检测触发时：先 `CanStepUp(direction)` 可跳则 `Jump()`（边前进边上升越过小坡），否则横向绕行。
- 新增字段：`_jumpForce`(默认8)、`_maxStepHeight`(默认1)。
- 注意：用户已将 `GuideController` 基类从 `MonoBehaviour` 改为 `Furniture_Base`（继承 `Furniture_Attached`），`Awake/OnEnable/OnDisable/Update` 均为 `protected override`。后续新代码需兼容该继承链。

## GuideController 卡住检测重写（消除无意义绕行）
- 用户反馈：有时障碍物不影响前进却无意义左右移动（卡住检测误触发）。
- 原因：原卡住检测比较"每帧到拐点距离减少量 > 0.05f"，角色接近拐点/转弯时每帧距离减少量 < 0.05f（尤其低帧率/慢速），被误判为卡住 → 触发绕行。
- 修复：改为"0.5 秒窗口内累计实际水平位移"判定：`accumulatedMove` 累计窗口内水平位移（用 `Vector3.Distance(horizontalNow, lastPos)`），0.5 秒后若 `accumulatedMove < _moveSpeed * 0.5 * 0.3`（正常移动量 30%）才判卡住。
- 效果：正常前进/接近拐点/转弯时累计位移超过 30% 阈值不误判；真正被挡时位移≈0 才触发。跳/绕行/到达分支均重置窗口。

## GuideController 到达时空中卡死修复
- 用户反馈：跳跃空中靠近目标点时直接卡在半空停下。
- 根因：`MoveRoutine` 到达最终目标点（遍历完拐点）即 break，break 后 `StopCoroutine(_gravityCoroutine)` 停止重力协程。若此时角色还在空中（跳跃未落地），重力停止后角色不再下落，冻结在半空。
- 修复：到达最终目标点且 `!isGrounded` 时，先 `while(_controller!=null && !_controller.isGrounded) yield return null;` 等待角色落地（期间 `GravityRoutine` 独立运行持续下落），落地后再 break 结束移动。`_controller==null` 时跳过等待直接 break 兜底。

  3. `MoveRoutine` 结束、`StopMoving` **不再停止重力协程**（重力始终有效，解决"卡在空中"根本问题）。
