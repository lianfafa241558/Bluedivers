# 2026-08-08

## SoundGroup_SO 工具方法：变成另一个 SO 的子资源
- 在 `SoundGroup_SO.cs` 的 `#region 工具`（UNITY_EDITOR）新增两个工具：
  - `[MenuItem("Assets/Tools/把选中 SoundGroup 变成选中物体的子资源")]` `AttachSelectedToAsset`：收集选中的 SoundGroup_SO，挂载为 `Selection.activeObject`（目标 SO 资产）的子资源。逻辑：先 `AssetDatabase.RemoveObjectFromAsset` 解绑旧引用，再 `AddObjectToAsset(group, parent)` 挂载，若原本是独立资产则 `DeleteAsset` 删旧文件，最后 SetDirty+SaveAssets+ImportAsset 并选中父资源。
  - `[ContextMenu("变成选中物体的子资源")]` `AttachSelfToAsset`：单实例版本，用法为先选中目标 SO，再在 SoundGroup 的右键菜单触发。
- 目标父资源不能是 SoundGroup_SO 本身（排除自身），必须为项目内资产。

## UseBag 键改造（BagBase 系列输入统一）
- 在 `InputManager.cs` 的 `InputState` 枚举新增 `[InspectorName("使用背包")] UseBag`。
- `PlayerInputHandler.cs` 新增 `GetUseBagDown()/GetUseBagHeld()/GetUseBagUp()`，均用 `CanProcessInput(WindowStateEnum.Game)` + `InputManager.GetDown/Get/GetUp(InputState.UseBag)`。
- 各 Bag 子类使用方式全部改为 UseBag 键：
  - `WeaponBag`：开火从 `fireSlot` 数字键改为 UseBag 的 down/held/up 驱动 `weapon.ShootInputs`。移除 `fireSlot` 字段及 `GetFireSlotDown/Held` 方法。
  - `Jetpack`：**保持空格触发（最终决定）**。Jetpack 是持续位移能力，与跳跃同属"位移"输入，改回 `GetJumpInputDown`（开启）+ `GetJumpInputHeld`（持续喷气），并恢复 `HasJumpedThisFrame` 保护。UseBag 留给"使用即触发"的装备。
  - `BlinkBag`：从长按(0.3s)+松开取消改为按下 UseBag 即闪现。移除 `isUse` 字段、`CancelUse()`、`useJump` 占用逻辑。
  - `ShieldBag`：纯被动，无输入改动。
- 最终键位分配：UseBag 用于 WeaponBag（开火）、BlinkBag（闪现）；Jetpack 用空格（跳跃键）。
- 注意：InputManager 默认按键绑定在 Inspector 序列化的 `inputList` 资产中，需用户手动给 UseBag 配置默认键，代码层无法设置。

## RoleData_SO.speechGroups 自定义检视器
- 新增 `Assets/Editor/Drawer/RoleSpeechGroupDrawer.cs`：`[CustomPropertyDrawer(typeof(DisplayDic<SpeechTypeEnum, SoundGroup_SO>))]`，参考 `WeaponCfg.cs`/`WeaponCfgOld.cs` 的 WeaponCfgDrawer 模式。
- 功能：标题行（label + 长度 + 清空 + "隐藏未配置"toggle，默认隐藏，因 SpeechTypeEnum 占位符多）；按 SpeechTypeEnum 逐项平铺，已配置项显示 SoundGroup 对象引用 + 删除按钮，未配置项（不隐藏时）显示禁用标签 + 添加按钮。
- 关键点：DisplayDic 内部用 arr(List<KVP<SpeechTypeEnum,SoundGroup_SO>>) 序列化、dic 缓存，增删后必须置 `meetReset=true` 触发 dic 重建（参考 WeaponCfgOld 的写法）。
- 隐藏状态用静态 Dictionary 按 propertyPath 缓存（仿 CampTemplateDrawer），避免多实例串扰。
- 枚举中文标签用反射取 InspectorName（仿 WeaponCfg.GetEnumString）。

## speechGroups 添加按钮改为子资源选择窗
- 新增 `Assets/Editor/Drawer/RoleSoundGroupPicker.cs`（`RoleSoundGroupPicker : EditorWindow`，`ShowUtility()` 工具浮窗仿自带 ObjectPicker）。`Show(assetPath, onSelect)` 用 `AssetDatabase.LoadAllAssetsAtPath` + `OfType<SoundGroup_SO>()` 仅列出指定 RoleData_SO 资产下的 SoundGroup 子资源；支持搜索过滤、单击选中、双击/确定回调、取消。
- 修改 `RoleSpeechGroupDrawer.cs` 的"添加"按钮：不再直接塞空项，改为 `RoleSoundGroupPicker.Show(path, callback)`。回调用 `new SerializedObject(targetObj)` + `propertyPath` 重新解析 `speechGroups`，写 Key(enumValueIndex)+Value(选中 SoundGroup)，置 meetReset=true 并 ApplyModifiedProperties + SetDirty。
- 注意：不能直接捕获 `SerializedProperty`（GUI 重绘后会失效），要捕获 `SerializedObject`+`propertyPath`+`targetObject`，回调里重建。
- 后调整：`RoleSpeechGroupDrawer` **移除"隐藏未配置"toggle 与 hideStates 逻辑**，始终显示全部 SpeechTypeEnum 枚举项（未配置的也显示"添加"按钮）。`GetPropertyHeight` 恒为 `(AllValues.Length+1)` 行高。
