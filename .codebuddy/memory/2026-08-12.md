- 需求：同一强化（id≠0）只允许一个玩家选择；某玩家选中后，其他玩家对应强化按钮禁用；自己当前已选的按钮保持可用（允许反悔更换）。id=0（未选择）不受限。
- 新增字段 `Dictionary<int, Transform> boosterButtons`（强化 id -> 按钮），在 `FirstShowWnd` 初始化、`InitBoosterButtons` 填充时登记（先 `Clear()`）。
- 新增 `RefreshBoosterButtons()`：遍历 `roomManager.players` 收集其他玩家已选强化 id（`boosterId>0`）为 occupied 集合，对自己面板每个强化按钮 `SetButtonInteractable(btn, kv.Key==myBooster || !occupied.Contains(kv.Key))`。
- 调用时机：`InitBoosterButtons()` 末尾（界面打开创建后）和 `ReceivePlayerSelectTeamEnhance` 末尾（任何玩家选择后，所有客户端收到回调都会刷新）。
- 相关数据确认：`RoomManager.players[i].boosterId`（int，RoomManager.cs:83）；`ResSvc.boostDic`（Dictionary<int,Booster_SO>）；`BattleManager._activeTeamEnhance` 为 `boosterId>0` 的玩家强化 type 数组（多强化可共存）。
- 禁用机制：`SetButtonInteractable`（WndRootTool 静态方法）→ `Button.interactable=false`（置灰 + 阻断点击）。注意：`ButtonEnterDetector` 的悬停提示不随 interactable 禁用，仍会显示。

## DRG 解包资源文件夹重命名（D:\岩深解包\DRGPacker4.27\Audio\SFX）
- 需求：为未标注中文的文件夹在英文后直接拼接中文名（用户确认格式=直接拼接，Forge 译"铸造厂"）。
- 改名 5 个：Forge→Forge铸造厂、HackingPod→HackingPod黑客舱、LevelElements→LevelElements关卡元素、UI→UI界面、WeaponsNTools→WeaponsNTools武器与工具。
- 其余原本带中文标注的文件夹（Balloon气球、Season_Christmas圣诞节等）保持不变。
- 后续又对全部 300+ 个子文件夹按父文件夹分批补充中文标注，全量校验通过无遗漏。
- 技术要点（PowerShell 批量重命名避坑）：
  1. write_to_file 写 .ps1 脚本文件时用无 BOM UTF-8，PowerShell 5.1 按 ANSI/GBK 读取会中文乱码解析失败 → 不要写脚本文件，改在内联 execute_command 里跑哈希表映射，中文能正常处理。
  2. 哈希表 @{} 的键若以数字开头（如 `0CustomSounds`）必须加引号 `'0CustomSounds'`，否则解析报错"哈希文本不完整"。
  3. 键名含下划线（如 `MineHead_Close`、`Hunter_ON`）或大写（`LowGRavitySwitch`）也应加引号避免歧义。
  4. 用 `$_.Name -notmatch '[\u4e00-\u9fff]'` 过滤已含中文的文件夹，避免重复改名。
  5. 分批策略：命令短、无编码问题，每批可即时复核。
