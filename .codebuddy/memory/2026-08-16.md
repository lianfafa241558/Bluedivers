## BattleManager.InitTerrain 三次 `TerrainUtils.Main = terrain` 分析
- `TerrainUtils.Main` setter（TerrainMainUtils.cs:11-27）是**惰性读取**：被赋值时从 `value.terrainData` 当前值刷新缓存 `heightmapRes/alphamapRes/terrainHeight`。
- InitTerrain 三处 set 作用：①建全局+取本地 terrain ②改 heightmap/alphamapResolution 后刷新分辨率缓存 ③改 size 后刷新 terrainHeight（供 AdditionTerrain）。
- 结论：②③可合并成一次，放在**所有 terrainData 修改（分辨率+size）之后**统一 set；①不可省（负责本地引用）。`terrainData.size` 与前面分辨率的顺序不可调换（原注释坑）。已向用户提供简化方案，待用户确认是否执行修改。
