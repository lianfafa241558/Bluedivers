## 修复 LX/Texture2 shader
- 文件：`Assets/Shader/Texture2.shader`（项目通用特效 shader，被 78 个材质引用，如 Laser/Halo/Glass/Shield）
- 问题 1：`_UseLight` 与 `_UseFresnel` 同时开启时 frag 内两处 `Light mainLight = GetMainLight();` 重定义 → 删除 `_UseFresnel` 块内重复且未用的声明
- 问题 2：开启 `_UseLight` 且材质用加法混合（`Blend SrcAlpha One`）时特效完全消失。根因：URP 场景无启用的 Directional Light 时 `_MainLightColor` 为黑，`col.rgb *= mainLight.color` 乘成 0；additive 下 `final = srcColor*srcAlpha + dst`，srcColor=0 → 物体完全不发光。
- 修复：`col.rgb *= lerp(lightColor, half3(1,1,1), dot(lightColor, half3(1,1,1)) < 0.001);` 无主光时退化为不乘光

## 新增护盾恢复技能 UnitSkill_ShieldRestore
- 文件：`Assets/Scripts/02Game/AI/Skill/UnitSkill_ShieldRestore.cs`（被动技能，类似 SympatheticDetonation 模式，非 UnitSkill_Base）
- 逻辑：监视两个 Damageable 肢体——`shield`（护盾）被摧毁（OnDestroyPart）后计时 `restoreDelay` 秒恢复；`emitter`（护盾发射器）被摧毁则 `m_EmitterBroken=true` 技能失效（含等待中 StopCoroutine），不再恢复护盾
- 依赖改动：`Damageable.cs` 新增公开方法 `RestoreArmor()`——记录 `maxArmor`（难度缩放后的满值）、`ArmorBreakEffect` 新增运行时字段 `originActive`/`originLocalScale`（Awake 记录），恢复时 remainArmor 回满 + showArmor 更新 + ArmorBreaker 置空 + 还原护甲破坏效果（SetActive + localScale）
- 备注：护盾即护甲（Destruction 伤害打破 remainArmor → OnDestroyPart），恢复依赖 Damageable 的 armorBreakEffect 还原

## 新增环绕装甲技能 UnitSkill_OrbitArmor
- 文件：`Assets/Scripts/02Game/AI/Skill/UnitSkill_OrbitArmor.cs`（继承 UnitSkill_Base 的主动技能）
- 逻辑：SkillStart 时以单位为中心，每 `360/count` 度、`orbitDistance` 距离环绕实例化 `armors`(List<GameObject>) 里的预制体；把每个创建单位的 `Health.MainPart` 通过主单位 `PartController.AddInvincibleArmor(damageable)` 注册为无敌装甲——全部装甲被打爆前主单位保持 Invincible（依赖 PartController 的 invincibleArmor 机制）
- 前置要求：主单位需挂 PartController；创建单位的 Health 需配置 MainPart
- 补充（参考 UnitSkill_Charge）：SkillStart 时 `m_Controller.Speed.AddModifier(ModifierType.Factor, 0)` 无敌期间速度归零，SkillEnd 时还原 `Factor, 1`（Duration 结束触发）
- 后改为无固定时长：`PartController.cs` 新增事件 `OnAllInvincibleArmorDestroyed`（invincibleArmor.Count 归 0 时触发）；技能 SkillStart 里 `nowDurationTime = 0` 禁用基类时长倒计时，监听该事件在全部装甲被摧毁后结束（恢复速度）。m_IsActive 防重复释放，registered==0 时回滚防永久静止
