# 2026-08-24

## 实现全队强化（Booster）逻辑（4 个，SampleSaver 暂缓）

全队强化通过 `BattleManager.Instance.HaveBooster(BoosterType.X)` 判断（`_activeTeamEnhance` 数组来自 `RoomManager.players[].boosterId`）。

- **友情护盾 FriendShield**：友军伤害再降低 50%（总友伤 25%，仅玩家阵营生效）。实现于 `Damageable.InflictDamage`（紧邻友军减伤，与 Vitality 强化同位置），新增私有静态辅助 `IsFriendlyUnit(Actor)`。
- **荆棘护甲 ThornArmor**：近战攻击玩家阵营单位时，攻击者受 24 点反伤。实现于 `FpsHelper.Hit` 直击分支 → `TryThornArmorReflect`（static）。近战判定：`hitData.weapon.ProjectilePrefab is ProjectileMelee`（近战只有 FpsHelper 层能拿到武器信息，Health 层不行，故未按用户最初建议放 Health.cs）。反伤伤害组 `ThornArmorDamageGroups`（Real 类型 24 点）。
- **补给大师 SuppleMaster**：`PlayerController.UseCaisson` 补充给后调用 `WeaponsManager.ReloadAllWeapons()`（新方法，遍历 m_WeaponSlots 调 `weapon.ReloadComplete()`）；`ReloadComplete()` 新增于 `WeaponReloadController`（public virtual，内部走 ReloadEnd，自动触发 WeaponController 的 UI 刷新）。`UseMedicalBag` 回血比例 0.5→0.6。
- **疾风二度 Windrunner**：`PlayerController.CurrentSprintCool` 属性 = `SprintCool * 0.8f`，`UpdateSprint` 改用该属性。
- PlayerController 新增私有辅助 `HaveBooster(BoosterType)`（判空 `BattleManager.Instance &&`，桥接场景无 BattleManager 时安全）。

## 设计要点/踩坑
- 全队强化只对玩家阵营（`UnitTypeEnum.Player/Friend`）生效，敌人互伤不受影响。
- 反伤走完整伤害链路（InflictDamage→TakeDamage），不会递归（反伤非近战，不经过 FpsHelper.Hit）。
- `IsValid()` 扩展对 `I_Damagable` 有效（ObjectIsValid 的 System.Object 重载）。
- PEInt 有 int 隐式转换（`PEMath.Clamp(CurrentHealth, 0, MaxHealth)` 已用）。
