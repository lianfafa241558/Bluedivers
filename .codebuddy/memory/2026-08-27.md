## EnemyMobile 追击散开（最终方案：先绕后锁）
- 问题：所有敌人 `FollowBehavior`/`AttackBehavior` 直接 `SetNavDestination(TargetPosition)`，直线追玩家挤成一团。
- 根因在 `EnemyMobile.cs`，`PathRequestManager`（寻路排队）与 `EnemyController` 无需改动。
- 早期方案（包围圈+拥挤滑动，`EnableEncircle`/`GetEncircleDestination`/`SlideToFreeSlot`）已**废弃并回滚**——实测效果不明显（单位仍像锁玩家坐标）。
- **最终方案**（全部在 `Assets/Scripts/02Game/AI/StateMachine/EnemyMobile.cs`）：
  1. 配置字段 `EncircleDistance=8f`（"环绕距离(米)"）：发现目标后先前往玩家周围该距离的随机角度点，接近到该距离内后才直接锁玩家。
  2. `_encircleAngle`：`OnDetectedTarget()` 首次从非战斗状态进入战斗（Idle/Patrol/Beware/Return→Follow）时 `Random.Range(0f, 360f)` 生成一次，一次追击固定角度。
  3. `FollowBehavior()` 两阶段：`followDis > EncircleDistance` 时目标点 = `TargetPosition + Quaternion.Euler(0,_encircleAngle,0)*(-dir)*EncircleDistance`（dir=单位→玩家的水平方向），即玩家周围随机角度的环绕点；接近到 `EncircleDistance` 内后 `SetNavDestination(TargetPosition)` 直接锁玩家。其余分支（stopRange/MaintainMaxDis/StopNav）保持原逻辑。
  4. `AttackBehavior` 已还原为原始逻辑（无环绕，进射程直接逼近/站桩）。
- 未改动 `EnemyController.cs`/`PathRequestManager.cs`。
- 调参：`EncircleDistance` 越小单位越早直接锁玩家；近战可调小（如 3~5m），远程可调大。

## ProjectileStandard 子弹穿透地形排查（分析中）
- 现象：子弹"有时候"穿透地面射到地下；离得近的 ground 层物体也被穿透。
- 已定位嫌疑原因（供后续验证）：
  1. `IsHitValid()` 中"发射后前 1m 不检测"规则 `(Time.time - m_ShootTime) * (m_Velocity + InheritedMuzzleVelocity).magnitude < 1f` → 直接解释"近处物体被穿透"（枪口离地面/墙 <1m 时全部忽略）。
  2. `Physics.SphereCastAll` 起点已在碰撞体内部（重叠）时不返回该碰撞体 → 一旦子弹中心越入地面（掉帧大 tick / 1m 规则导致第一帧跳过），后续每帧起点在地形内 → 永久穿透射到地下。
  3. 预制体 Tip 子物体在 Root 前方 0.25m，`displacementSinceLastFrame = Tip.position - m_LastRootPosition` 每帧多扫 0.25m（正常无害，贴地慢速时探入地面）。
  4. 需排除：子弹 BulletFlag 是否误勾 `PenetrateTerrain`（`IsHitValid` 会忽略所有无 I_Damagable 的地形）。
- 已添加调试绘制（`ProjectileStandard.cs` 新增 `DebugDraw` 字段，`#if UNITY_EDITOR` 包裹）：
  - 黄线=本帧扫掠段(上帧Root→本帧Tip)；青/绿球=扫掠两端；白线=本帧实际位移；红球=命中点；品红线=命中法线；灰球=被"1m 规则"拒绝的命中点。
  - Scene 视图勾选子弹 Inspector 的"绘制扫掠调试线"即可观察。

## 2026-08-27 根因确认与修复
- **根因（off-by-one）**：`ProjectileStandard.Update()` 中 `dis` 在 `Move()` **之前**计算。首帧子弹未移动 `dis=0`，`if (dis > MinRange)`（`0 > 0`=false）跳过第一次检测；而 `Move()` 已把高速子弹(1000m/s)推出 ~16.7m。第二帧才首次 `TryHit()`，但扫掠起点 `m_LastRootPosition`=发射点+16.7m——斜下45°射击时已深入地面 ~11.8m。`SphereCastAll` 起点在碰撞体内部时不返回该碰撞体 → 地面永远扫不到 → hits=0 → 永久穿地射到地下。同时解释了"黄线10m后出现/近处物体被穿透/扫掠len远小于dis"等全部现象。
- **修复**：`if (dis>MinRange)` → `if (dis >= MinRange)`，首帧(dis=0)即参与检测，扫掠段起点=发射点，完整覆盖首段路径。对 MinRange>0 的武器（如 Colossus MinRange=12）语义不变（dis≥12 才检测）。
- 另加诊断：发射日志中打印"发射点离地高度"（从上方100m向下采样 `LayerDefinition.GroundLayers`），用于区分修复后是否仍因枪口穿模(发射点本身在地面下)而穿地。
- 待验证：修复后复测斜下射击，若仍 hits=0，检查发射点离地高度日志是否为负（枪口穿模）→ 需从武器侧解决枪口位置。
