# 2026-08-31

## DeployableMine 高空单位误引爆修复
- 根因：治疗无人机 `HealdroneBase.prefab` 等飞行单位 `halfHeight: 0`，原 `InVerticalRange` 对 `HalfHeight <= 0` 直接放行（"0=不做高度过滤"约定），导致高空掠过仍引爆。
- 修复：`InVerticalRange` 重写为 `InTriggerRange` 实际 3D 距离判定——竖直间隙按 [CenterPos.y - HalfHeight, CenterPos.y + HalfHeight]（未配置退化为中心点本身），水平间隙 = 中心距 - actor.HalfRange（保巨型单位黏附可引爆），两者合成 sqrt 后与触发距离比较。
- 隐患提示：halfHeight=0 的**地面**单位（如 Dec_Bane/Dec_Roach/Dec_Front/Dec_Back）现在按中心点算竖直距离，若其 AimPoint 离地超过触发距离(默认0.7)会炸不到，需用批量工具补 halfHeight。
- `VerticalRange` 字段语义改为"实际3D距离容差(0=同触发范围)"，Inspector 名改为"触发距离(0=同触发范围)"。

## Damageable.cs 方法注释补全

## PlayerWeaponsManager 武器槽位映射重构（枚举与槽位解耦）
- 背景：`WeaponTypeEnum` 新增 Support/Empty，原"槽位 = (int)枚举值"的隐式约定失效。
- 新映射（`PlayerWeaponsManager` 顶部静态表）：主0/副1/**支援2/特殊3**/投掷4/信号枪5/空手6/护甲7(占位)。提供 `SlotOf(WeaponTypeEnum)`、`SlotToWeaponType[]`、`IsSwitchableSlot(int)`、`MaxSwitchableSlotIndex=3`、`SwitchableSlotCount=4`。
- 滚轮/数字键只在槽位 0-3 切换（数字键 1-4）；投掷/信号枪保持各自呼出方式（G键/蹲键）；`SwitchWeapon` 循环与 `GetDistanceBetweenWeaponSlots` 回绕均限定 SwitchableSlotCount。
- `AddWeapon` 改为按 `weaponPrefab.WeaponTypeEnum` 映射槽位落位（依赖 `WeaponPlayerController.WeaponTypeEnum` 字段在 Inspector 正确配置），槽位被占返回 false。
- 家具操作（`OnOperation`）由原来的 FlareGun+1（旧 Armor 占位槽）改为切到 `SlotOf(Empty)`；恢复时用 `IsSwitchableSlot(m_LastWeaponIndex)` 判断，不可切换则回槽 0。
- 连带修改：`PlayerWnd.cs:289` 手雷槽位改用 `PlayerWeaponsManager.SlotOf(...)`。
- **遗留提醒**：`PlayerWnd.cs:122-126` 武器栏 UI 仍只显示槽位 0-2 图标（新映射下是 主/副/支援，特殊武器在槽3），如需显示4把需 UI 加子项。
- 支援武器空槽排查（2026-08-31）：滚轮/数字键（`GetWeaponAtSlotIndex()!=null` 守卫）、`SwitchWeapon`（跳过空槽）、`ReplaceWeapons`/`ChangeWeapon`（null 武器 → 状态 Down）均安全；唯一 NRE 点是 `PlayerWnd` 初始化设图标循环，已加 `item ? item.WeaponIcon : null` 判空（`SetSprite` 传 null 仅清空 Image，安全）。注意 `PlayerWnd.AddWeapon` 回调是空实现，捡起支援武器后图标不会自动刷新，实现捡起功能时需补。
