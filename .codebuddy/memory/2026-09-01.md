# 2026-09-01 Bluedivers 开发日志

## 手持装备系统（HandEquip + Furniture_HandEquip）— 已实现
- **需求**：新建继承 Furniture_Base 的交互家具类 + 对应装备类。交互时装备"拿在手里"、玩家武器强制切空手、移速 -50%；经"丢弃装备"轮盘（EquipmentUninitiatedUI + InputState.Equip）卸载。
- **关键决策**（用户澄清）：**不进武器槽**，作为独立装备（类似护盾背包/喷气背包）由 EquipController 管理，额外在手上显示模型；移速用 `PlayerController.MoveSpeedScale *=0.5`（装）/`/=0.5`（卸）。
- **新增文件**：
  - `02Game/Gameplay/Bag/HandEquip.cs`：实现 IEquippable。`OnInstall`：挂到 `m_Player.HandPoint`（拾取道具点，不再挂 Hand 骨骼）、设左右手 IK（`m_FullIK.solver.left/rightHandEffector.target = LHand/RHand`，weight 1/0，m_FullIK=`GetComponentInChildren<FullBodyBipedIK>`）、`wm.SwitchToWeaponIndex(SlotOf(Empty),true,false)` 强制切空手、`m_Player.MoveSpeedScale *= MoveSpeedScaleModifier(0.5)`、订阅玩家事件。`OnUninstall`：退订事件、清 IK（target=null，weight 0）、`/= MoveSpeedScaleModifier` 恢复、`SetParent(null,true)` 落地、按需 `wm.SwitchWeapon(true)` 切回主武器。`OnDestroy` 兜底恢复移速+退订。IEquippable.Owner 显式实现（I_Actor）；ID 取 `GetComponent<IFurniture>().Id`；HaveFlag/NeedUninstall=false。
  - `02Game/05Interactable/Furniture_HandEquip.cs`：继承 Furniture_Base。覆写 ShowName/Id（返回 equipName 字段，避免基类取 _actor NRE——地面实体无 I_Actor）；`CanOperate`=基类条件 && 有 HandEquip && 交互者是玩家 && `!equips.ContainsKey(m_Equip)`（防重复拾取）；`Operate` 用 inOperate 区分：false=InstallEquip+inOperate=true+canOperate=false+`enabled=false`（禁用跟随手部脱离交互列表）；true=UninstallEquip+ResetForPickup+`enabled=true`。`ResetForPickup` 复位 canOperate/inOperate/owner/pressTime。不调 base.Operate() 避免 FurnitureOperate 副作用。
- **HandEquip 增强（2026-09-01 第二轮）**：加 `LHand`/`RHand`（Transform，IK 握点）+ `CanEnterVehicle`（bool，false 则进载具丢下）字段；父物体挂 `PlayerController.HandPoint`；IK 用玩家 `FullBodyBipedIK`。自动丢下（`Drop()`→UninstallEquip→OnUninstall，`m_SkipRestoreWeapon=true` 跳过切回武器）：①玩家切到非空手武器（订阅 `m_Weapons.OnSwitchedToWeapon`，过滤 Empty）②玩家倒地（订阅 `m_Health.OnDie`）③进载具且 `!CanEnterVehicle`（订阅 `m_Player.OnEnterVehicle`）。轮盘主动卸载仍 `m_SkipRestoreWeapon=false` 会切回主武器。
  - `02Game/03Player/MainController/PlayerController_HandEquip.cs`（新增分部）：`public event UnityAction OnEnterVehicle;`。主文件 `PlayerController.OnDisable` 末尾广播 `OnEnterVehicle?.Invoke()`（进载具被禁用时触发）。
- **模式复用**：与 `Furniture_WeaponPickup`（武器拾取）+ `Furniture_Equip`（装备安装/卸载）一致。轮盘卸载不经过 Handle，`owner` 依赖拾取时残留的玩家引用。
- **用户需手动配置**：①装备预制体根物体挂 `Furniture_HandEquip` + `HandEquip` 两个组件 ②加 Collider（可在子物体，第一人称射线已 GetComponentInParent）③配置 `equipName`（轮盘/交互提示）、`Portrait`（轮盘图标）、`HandOffset`/`HandEuler`（手持位置）、`LHand`/`RHand`（IK 握点，挂装备模型上的两个手部空物体）、`CanEnterVehicle`（是否可带上载具）④场景摆放地面装备实体验证。链路：交互拾取→挂 HandPoint+IK+切空手+移速-50%→滚轮/数字键切武器或倒地或进载具→自动丢下→轮盘卸载→恢复移速+切回主武器+落地可再拾取。
- **注意**：卸载落地位置是卸载时手部世界坐标（`SetParent(null,true)` 保留），若在空中可能需后续优化落地采样。

## 玩家承载点位组件 PlayerMountPoint（2026-09-01 第三轮）— 抽出 IK+点位
- **背景**：用户决定把 IK + HandPoint 抽成独立组件，并新增背部点位给 BagBase（背包装备）用。
- **新增 `02Game/03Player/PlayerMountPoint.cs`**（Unity.FPS.Game）：集中管理玩家挂载点与手部 IK。`[SerializeField] handPoint`（拾取道具点，手持装备用）+ `backPoint`（背部点位，背包装备用）+ `fullIK`（FullBodyBipedIK，Awake 自动 GetComponentInChildren）。公开 `HandPoint`/`BackPoint`。`SetHandIK(lHand, rHand)`（设 target+weight，null 的手 weight=0）/`ClearHandIK()`（清空 target+weight 0）。Awake 兼容旧配置：handPoint 未配置时从 `PlayerController.HandPoint` 读取。
- **修改 `HandEquip.cs`**：移除 `m_FullIK` 字段改为 `m_MountPoint`（`GetComponent<PlayerMountPoint>()`）；`OnInstall` 父物体用 `m_MountPoint.HandPoint`（回退 m_MountPoint.transform/m_Player.transform）、IK 用 `m_MountPoint.SetHandIK(LHand,RHand)`；`OnUninstall` 用 `m_MountPoint.ClearHandIK()`。
- **修改 `BagBase.cs`**：`OnInstall` 挂载点由 `ModleRoot` 改为 `mountPoint.BackPoint`（回退 ModleRoot）。
- **兼容策略**：`PlayerController.HandPoint` 保留但已无直接运行时引用（仅 PlayerMountPoint 兼容读取）。用户应把 Inspector 里的 HandPoint 赋值迁移到 `PlayerMountPoint.handPoint`；`PlayerMountPoint.backPoint` 需在玩家预制体上配置（背部骨骼空物体）。
- **架构要点**：IK/点位从 `PlayerWeaponsManager`（武器）和 `HandEquip`（装备）中抽取统一到 PlayerMountPoint，避免各系统重复操作 m_fullIK。`PlayerWeaponsManager` 的 IK 暂未迁移（有双持复杂逻辑，保留原样）。
- **PlayerMountPoint 动态模型适配（2026-09-01 修正）**：玩家模型是**动态加载**的（`PlayerController.SetBody`），`FullBodyBipedIK` 和背部点都在动态模型内，**不能在 Awake 解析**。改为订阅 `PlayerController.OnBodySet`（SetBody 末尾广播）动态解析：`fullIK = GetComponentInChildren<FullBodyBipedIK>()`、`backPoint` 按 tag（默认 `BackPoint`）在 `ModleRoot` 递归查找。每次换模型重新解析（覆盖旧引用）。handPoint 仍 Awake 兼容读取 `PlayerController.HandPoint`。`PlayerController_HandEquip.cs` 分部新增 `OnBodySet` 事件（与 OnEnterVehicle 同文件）。
