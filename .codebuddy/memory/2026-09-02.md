## 新增 Furniture_Artillery 家具（配合炮弹架阶段）
- 新建 `Assets/Scripts/02Game/05Interactable/Furniture_Artillery.cs`，继承 `Furniture_Attached`。
- 字段：`requireId`(所需物体ID, string)、`maxProgress`(进度上限, int=5)、`placePoint`(放置点位, Transform)；只读 `Progress`。
- `CanOperate`：基类条件 && `Progress < maxProgress` && 玩家(EquipController)手持 `Id==requireId` 的物体。
- `Operate`：找到玩家手持匹配物体 → `UninstallEquip` 放下 → 禁用物体上家具(MonoBehaviour.enabled=false) → 关闭其 CharacterController → 移到 placePoint → Progress+1 → `base.Operate()`(触发 OnFurnitureOperate 推进 KeyScreen 进度) → 复位 inOperate/owner 允许连续放置。
- 与 KeyScreen.Artillery 联动：KeyScreen 的 now.furns 需包含该 Furniture_Artillery 实例，靠 NumberID 匹配。
