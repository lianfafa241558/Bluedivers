## 抽象基类 Furniture_OOPartDepositBase（方案A：接管按压）
- 路径：Assets/Scripts/02Game/05Interactable/Furniture_OOPartDepositBase.cs（全局命名空间，继承 Furniture_Base **并实现 IStepPress**）
- 关键结论：现有 PlayerOperationController 长按期间无逐帧回调（只 `target.Press+=dt`，到 `MeetTime` 才 Handle），且松开只归零 Press 不通知家具，**无法实现"按住时逐步扣减+松开保留"**。要支持需让家具接管按住过程 → 改造控制器。
- 新增接口 IStepPress（Assets/Scripts/02Game/05Interactable/IStepPress.cs，全局，I 前缀无下划线）：CanOperateStepped(unit) / BeginPress(unit)（按下瞬间锁定并复位，返回是否开始）/ StepPress(dt)（逐帧推进，返回是否转完）/ CancelPress()（取消保留）。
- 控制器改动（PlayerOperationController.cs，仅对实现 IStepPress 的目标走新路径，原逻辑对其它家具不变）：
  - 在 `if(target!=null)` 内**顶部**先判断 `target is IStepPress step && step.CanOperateStepped(gameObject)`：down→BeginPress（成功则播 AudioPress 循环音）；held→StepPress 返回 true 才 Handle()→Operate()；up→CancelPress()。非 IStepPress 走原瞬时(MeetTime==0)/长按逻辑。
  - 新增私有方法 CancelSteppedPress()，在 TrySetTarget / ClearTarget / OnWindowStateChange(非Game) / 第三人称 target!=newtar 切换处调用，避免切换/关窗打断接管按压。
  - 注意 IStepPress 家具**不能设 MeetTime==0**（否则控制器走瞬时分支）；BeginPress 时写 meetTime=need/10 供 OperationWnd 进度条。
- 抽象类行为（通用任意类型，无 oopartType）：
  - capacity(int 容纳上限)+held(已容纳)；RemainingSpace=capacity-held。
  - CanOperate：`_pressing 且 unit==_pressUser` 时豁免返回 true（防瞄准循环因包空/将满提前 ClearTarget 打断收尾）；否则 CoreCanOperate=base.CanOperate && bag.CurrentCount>0 && RemainingSpace>0。
  - BeginPress：锁 need=min(RemainingSpace, bag.CurrentCount)（只用包总数量 CurrentCount，任意类型），时长仅按下算一次；meetTime=need*PerUnitTime；复位 pressTime/_transferred/_stepAcc/_pressing/_pressUser。
  - StepPress：pressTime+=dt；_stepAcc+=dt；while(transferred<need && _stepAcc>=0.1f){ _stepAcc-=0.1; RemoveAnyOne(bag,out type) 成功则 held++、_transferred++、OnSubmit(user,type)；取空则视为完成 }；返回 transferred>=need。
  - CancelPress：清 _pressing/_pressUser/_need/_transferred/_stepAcc/pressTime（保留 held 已转移）。
  - Operate：base.Operate() 后 ResetPressState()；held>=capacity 则 canOperate=false（不触发 OnPressCancel）。
  - RemoveAnyOne(bag,out type)：遍历 bag.GetAll()（≤8种）逐类型 Remove 1 个（0.1s 一次，频率低可接受）。
  - 抽象钩子 OnSubmit(GameObject user, OOPartEnum type)：每成功转移 1 个调一次，子类覆盖。
  - 收尾钩子 OnPressCancel(GameObject user, int transferred)：**仅在玩家松开/中断(IStepPress.CancelPress)触发，转满完成(Operate)不触发**（用户最终定夺：完成由 Operate 表达）。IStepPress.CancelPress()（控制器 up/切换/清目标/关窗）复位前取 user=_pressUser、transferred=_transferred，ResetPressState() 后触发。Operate() 只 base.Operate()+ResetPressState()，不触发钩子。
  - **最终保留模型**（用户带例子澄清，覆盖早前"松开清空下次从0"）：矿石按住中已扣除且不退回，转成"内容物"保留；本次时长=min(capacity-held, 玩家矿石)/10；松开保留进度，下次按剩余累计（如已装1/上限10/手上5→0.5s；按0.3s装3发松开→下次 min(10-4,手上)/10）。ResetPressState() 为无钩子复位，仅 StepPress 内 _pressUser 失效异常路径调用。
  - 注意 OperationWnd 第一人称用 furn.Press/MeetTime 显示进度；第三人称不显示操作条。
- OOPartEnum 定义于 Assets/Scripts/01Manager/Bridge/PropertyManager.cs 全局命名空间（Pyroxene/Battery/Crystal/Dodecahedron/Ether/Glasses/Pendant/Voynich）；Foldout/DisplayField/DisplayFieldEnum 在 FPSGame.Attribute（00Attribute/CustomAttribute.cs）。

## 子类 Furniture_PlayerArtillery（欧帕兹装填炮弹架，重写）
- 路径：Assets/Scripts/02Game/05Interactable/Furniture_PlayerArtillery.cs，继承 Furniture_OOPartDepositBase。
- 含义：该架=火炮 WeaponController(m_weapon)，矿石=弹药，每矿石转 1 发炮弹。shells(List<int>) 记录每发伤害档位 index；射击时 OnShoot 从 shells 末弹出→UseDamageIndex；Magazine.CurrValue=shells.Count(弹匣量=已装发数)。原 PlaceHeldItem(手持物体)逻辑已整体被矿石装填取代。
- OnSubmit：BattleManager.Instance.BattleRandom.Range 抽 ShellIndexPool{0,1,3,4,5}（无2）→ shells.Add；m_weapon.Magazine.CurrValue=shells.Count。基类已 held++。
- Awake：held=shells.Count（预置炮弹同步）；OnShoot 弹出后 held=shells.Count、held<capacity 时 canOperate=true（支持发射后腾位再装）。
- OnPressCancel：空实现（保留模型，松开不清空）。capacity 为上限(Inspector, 不再用 ExtFloatParameter)。容量字段 held 与 shells.Count 需始终同步，否则 RemainingSpace 算错。
- 注意 BattleRandom.Range 扩展方法在 RandomUtils(全局, 00Tools/Test)；Magazine.CurrValue 可 int 隐式赋 PEInt。
- 监听战备释放：Furniture_PlayerArtillery 在 OnEnable/OnDisable 订阅/退订 BattleEventSub.OnAirdrop(GameObject source, GameObject beacon, Vector3 point, AirdropData)。回调里若 data.cfg.ID == Constants.PlayerArtilleryAId(19) 则 shells.Add(0)（补一发 0 档位，OnShoot 弹出即被打出）。data.cfg 是 AirdropData_SO，其 ID 为 int；该事件由 Effect/VFX/VFXAirdropEffect.cs 的信标落地时 BattleEventSub.Airdrop(...) 全局广播（含 null 来源，A/B 架均收，按 data.cfg.ID 过滤）。事件定义在 Assets/Scripts/01Manager/Battle/BattleEventSub.cs 第 60-61 行，AirdropData 嵌套于 AirdropController(全局类, 01Manager/Battle/AirdropController.cs)。
