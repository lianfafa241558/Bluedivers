## SimpleDecal_Colour.shader（新建）
- 基于 `Assets/Shader/SimpleDecal.shader` 新建 `Assets/Shader/SimpleDecal_Colour.shader`（Shader 名 `Decal/SimpleDecal_Colour`），移植 ToonLit 的"色彩"效果到屏幕空间贴花：①贴花 UV 采样 `_ColourMaskTex*_ColourColor` 作遮罩（对应 GetFinalColourColor）②由 decalSpaceScenePos 重建投影点世界坐标，用视角方向.xy 采样 `_ColourTex`（对应 ShadeColour）③`(1-mask)*base+colourResult` 后 `lerp(_ColourScale)` 合成（对应 CompositeAllLightResults）。
- 关键点：贴花无光照，ToonLit 原公式 `_ColourScale+rawLightSum*(1-_ColourScale)` 的光照项由 `_ColourScale` 直接承载为效果强度；`DisableBatching=True` 保证 `GetObjectToWorldMatrix()` 重建 WS 正确；视角 UV 采用了修正写法 `xy*_ColourTex_ST.xy+_ColourTex_ST.zw`（未沿用 ToonLit ShadeColour 中 xy+zw 相加的疑似笔误）。
- 同日按用户要求精简：去掉 `_MainTex/_Color/_EmittierColor/_AlphaRemap/_UseMaskMap/_UseColour`，只留色彩核心；随后又要求把 `_ColourMaskTex` 补回（最终形态：颜色 = `_ColourTex(视角.xz UV) × _ColourMaskTex(贴花UV) × _ColourColor × _ColourScale`，透明度 = 遮罩亮度 × `_ColourColor.a`），仍保留贴花框架（深度重建/Stencil/Blend/预乘Alpha/雾效）。
- **视角采样 UV 轴向适配（重要经验）**：ToonLit 的"色彩"用 `viewDirectionWS.xy` 采样 `_ColourTex`，前提是观察方向沿 Z 轴（角色）；地面印花从 Y 轴俯视时视线 ≈ (0,-1,0)，`.xy` 的 y 分量恒定、只有 x 微变 → UV 退化成一条线，画面出现条纹拉伸。`.xz` 只修好俯视、正视又坏——**最终方案：对视角方向做三平面采样**（zy/xz/xy 三组分量各采一次，按 `pow(abs(viewDir),4)` 归一化权重混合，某组退化时权重趋 0 条纹被隐藏），任意视角都成立。通用经验：3D 方向采样 2D 贴图、要求全角度稳定时用三平面混合。
- 同日已把 `ToonLit_LightingEquation.hlsl` 的 `ShadeColour` 也改成同款三平面采样（用 `lightingData.viewDirectionWS`，已归一化），顺带消掉了原来 `xy*(xy+zw)` 的 ST 笔误，与 SimpleDecal_Colour 实现一致。
- 2026-09-08：SimpleDecal_Colour.shader 已被用户移到 `Assets/Shader/Decal/` 下，并补回 `_MainTex/_Color`（无 _EmittierColor/_AlphaRemap/_UseMaskMap）。最终合成：`baseCol = _MainTex*_Color`；`withColour = (1-colourMask)*baseCol + viewColour*colourMask`；`col.rgb = lerp(baseCol, withColour, _ColourScale)`；`alpha = max(baseCol.a, 遮罩亮度*_ColourColor.a)`。
