## 积雪幽灵：溶解成透明的物体为什么还盖雪（PipelineA / polySurface28）
- 现象：`Assets/Resources/Prefabs/BattleBase/PipelineA.prefab` 的 polySurface28（材质 `Assets/Art/Modle/Mission/Pipeline/Pipeline_ncl.mat`，Shader `ToonLit/ToonLit`）`_UseAlphaClipping=1`/`_UseAlphaUV=1`/`_DissolveValue=0.93`，按 `ToonLit_Shared.hlsl` 的 `dissolve = _DissolveValue.r*1.2-0.1 = 1.016 > 1` → alpha 恒 0 → `clip()` 把每个片元丢掉，物体在 ToonLit 所有 pass 里完全不可见；但积雪仍在同位置画出轮廓。
- 根因：积雪**不是后处理，而是重画**。`SnowRendererFeature.SnowRenderPass.Execute` 用 `context.DrawRenderers(cullResults, drawingSettings{overrideMaterial=雪材质}, filteringSettings{RenderQueueRange.all, snowLayerMask})` 把命中层里的几何体重提交一遍，雪材质（`Custom/SnowOverlay`）完全不知道原材质是谁，也没有任何 clip/溶解逻辑。被 clip 掉的像素没写深度 → 深度缓冲里是管道后面的东西 → SnowOverlay（Transparent、`ZTest LEqual`、`ZWrite Off`）按几何真实位置深度测试通过 → 雪色按 mask alpha 混合上去。
- 关键数据：`Assets/Setting/New Universal Render Pipeline Asset_Renderer.asset` 的 `snowEntries[0]` mask=65（bit0 Default + bit6 Unit）→ `SnowOverlay_Unit.mat`（_SnowAmount 0.9 / Threshold 0.2 / Softness 0.1）；`snowEntries[1]` mask=8（Ground）→ `SnowOverlay_Ground.mat`。polySurface28 在 **layer 0 Default**，被第一条命中。
- 结论/建议：排除只能是**层**级别（挪到任何 snowEntry mask 之外，或收窄 mask 去掉 Default）；想让雪层复刻溶解不通用——`DrawRenderers` 整批共用一份 override 材质且不接受 MaterialPropertyBlock，拿不到逐物体的 `_DissolveValue`/`_AlphaMap`（除非改逐 renderer `cmd.DrawRenderer`，或用全局阈值近似）。另注意改成真 Alpha 混合透明也无效：ToonLit ForwardLit 写死 `ZWrite On`，同深度 LEqual 仍会通过。
