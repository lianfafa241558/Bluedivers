# 2026-09-29

## 动态撤离任务联动次要撤离区（选离玩家最近的点）

需求（用户）：`MissionEvacuateStatic` 已能与「次要撤离区」(`MissionEvacuateSecondary`) 联动；现在让 **`MissionEvacuateMobile`（动态撤离）也联动：发起撤离时选「离玩家最近」的撤离点作为实际使用的点**。

### 落地（4 文件）

1. **`MissionEvacuateBase.cs`（基类，上提复用点）**：新增 `using System.Collections.Generic;`；新增字段
   `protected readonly List<MissionEvacuateSecondary> _secondaryZones = new();` 与
   `public void SetSecondaryZones(List<MissionEvacuateSecondary> zones)`（Clear + AddRange，含 null 保护）。
   静态/动态撤离都继承它。
2. **`MissionEvacuateStatic.cs`**：删掉自己那份 `_secondaryZones` 字段与 `SetSecondaryZones` 方法（现用基类的）。其余 `CallSecondaryBeacons/OnSecondaryActivated/Uninit` 不变（照旧访问继承来的 `_secondaryZones`）。
3. **`MissionEvacuateMobile.cs`**：`OnStartEvacuate(user)` 开头插入 `SelectNearestEvacuatePoint(user);`。新增两个私有方法：
   - `SelectNearestEvacuatePoint(user)`：候选 = **本任务自己的撤离点(areaPoint)** ∪ 各次要撤离区；取离玩家最近的一处，命中次要区时把 `area=zone.EvacuateAnchor; areaPoint=zone.EvacuatePoint; pos=areaPoint;`（随后 `CreatMedivac`/`BattleEventSub.Evacuate` 都用新点）。最近的仍是自己的点则原样不动。
   - `GetEvacuateRequestPos(user)`：优先交互玩家位置；否则取离当前撤离点最近的玩家（`ActorsManager.Players` + `IsValidMono()`）；再否则退回 `areaPoint`（快速模式）。
   - 关键：动态撤离**不呼叫信标**（信标是静态撤离的玩家选择机制），只在发起时按距离自动选点；故无需 Hide 其它信标。
4. **`MissionController.cs`**：两处注入点（`InitAllMission` / `CollectMissionsFromScene`）由
   `if (evacuate is MissionEvacuateStatic s) s.SetSecondaryZones(evacZones);`
   改为 `if (evacuate is MissionEvacuateBase eb) eb.SetSecondaryZones(evacZones);`（静态/动态通吃），并同步中文注释。
