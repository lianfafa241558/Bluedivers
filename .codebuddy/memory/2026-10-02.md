- 侦察结论（可复用）：`DetectionModule.CanLook(pos, ignoreAngle, out hit)` = 视野角度(`FastAngleScale` 查表 × `DetectionRange`) + `Physics.Raycast(LayerDefinition.UnitSeeLayers)`，但它是 **protected** 且对烟幕层有副作用（会改 `TimeLastSeenTarget`）⇒ 应新加无副作用的 `HasLineOfSight(Vector3)` 公开封装，别直接复用 `CanLook`。
- 现有 Beware 链路（`EnemyMobile.cs`）：`EnterBeware`(取点:SearchPoint>BewarePoint>原点 并消费) → `BewareBehavior`(每帧下发 + 炮塔水平朝点) → 迁移(见敌→Follow；到达 `BewareReachRadius` 或 超 `BewareTimeout=20s` → Return) → Return 里先"已回原点"判 Idle/Patrol、再"停留 `BewareStayDuration` 到"下发原点。
- **待拍板 4 点**：① 是否加"距离门槛 `BewareObserveDistance`"（不加 ⇒ 远距离一眼看见就走，AI 显敷衍）；② "附近没敌人"用哪个口径（只靠现有 `IsSeeingTarget` 隐含 / 显式按半径 `UnitQuery.FindUnits` 查零敌人 / 仅在观察点查）；③ 观察点是否停留+左右扫视（复用 `BewareStayDuration`）；④ `SearchPoint`（追击最后已知位置）与 `BewarePoint`（噪声）是否用不同观察距离。
- 讨论结论：视线判据建议 `ignoreAngle=true`（只看遮挡）避免身体朝向抖动导致状态抖动；需 `BewareObserveSettleTime`(~0.4s) 连续满足防抖；`BewareObserveDistance<=0` 作开关以退化为现逻辑。
