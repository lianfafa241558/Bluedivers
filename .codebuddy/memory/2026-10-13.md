## 咨询：让网友提前内测，是否必须用内网穿透（只读调研，未改代码）

- **核心结论**：不是必须；而且**常用的免费"内网穿透"（ngrok / 花生壳 / cpolar 免费版）对本项目基本无效** —— 它们只转发 TCP，而联机层是 **UDP**（KCP 主通道 17666/udp + 发现 29800/udp 广播）。自建方案里只有 **frp** 能做 UDP（`type = udp`），但需要一台公网服务器，而且**广播包转不了** ⇒ 玩家只能用刚做好的「手动直连」。
- **推荐次序**：① **虚拟局域网**（ZeroTier / Radmin VPN / Hamachi / 蒲公英）—— 0 成本 0 代码，把对方直接当成同一局域网；⚠ ZeroTier 是 L2（广播**可能**可用，未实测），**Tailscale 是 L3/WireGuard、不转发 255.255.255.255 广播** ⇒ 必须走直连。② 房主有公网 IPv4（找运营商要）或双方有公网 IPv6 ⇒ 端口映射 + 直连，延迟最低。③ frp 中转（云服务器成本 + 流量/延迟吃亏）。④ Steam Playtest（免费 + Valve 中继，但要接 Steamworks SDK 并上架）。
- ⚠ **本项目该层的已知限制（未修）**：`NetHostSvc.StartHost` 固定 `StartAsServer("0.0.0.0", 17666)`（全网卡监听 ⇒ 虚拟网卡也能收，OK）；但 **`ServerListPanel.TryParseDirect` 不支持 IPv6** —— 它用 `s.LastIndexOf(':')` 切端口，`::1` 会被切成 ip=":" / port=1，`[::1]:17666` 虽切得对但 `IPAddress.TryParse("[::1]")` 会失败 ⇒ **走 IPv6 内测前必须先修**（识别方括号 / 多冒号时按括号切）。
- 顺手提议（未做）：房间列表面板显示"本机 IP"，方便房主把地址发给网友。

## ✅ 机甲"落地→悬浮 4 米→再掉下来"死循环（用户当场在 Play 里，"单机也复现"）

- **根因（实锤，非网络问题）**：`BaseSelfMoveableController.IsPenetrating` **只排除了根上的 CharacterController，没排除自身子物体**（`:658-663` 原判据 `if (c != Controller && c.transform != transform) return true;`）。机甲（Exosuit）的骨头上一串 BoxCollider（`layer=6 Unit`）就在自己胶囊里 ⇒ 复算当场命中 **14 个碰撞体、其中 13 个 `isSelfChild=True`** ⇒ `IsPenetrating` **恒为 true**。
  - 于是每帧 `HandleAutoEscapeFromOverlap`（`:624-644`，1s 冷却 + 0.3s 累积）必然判定"被压住"；水平脱困（`:697-714`，半径 ≤1.8m）必然失败（子碰撞体跟着走）⇒ 走 `TryEscapeUpward`（`:681-694`，0.1m/步、上限 `height*1.2`）⇒ 机甲胶囊 `height=4.5/radius=1.3` ⇒ **往上瞬移 ≈4 米**（console 实测 `挣脱到 (383.15, 25.05 / 14.58 / 14.48, 582.99)`）⇒ 重力拽回 ⇒ 冷却 1s 后再来一次 = "落到地上又悬浮 4 米再掉下来"。
  - ⚠ `Player(Clone)` 也中过一次 ⇒ **这是通用误判**，不是机甲专属；`LayerDefinition.MoveableLayers = -1`（Everything）放大了它。
  - 同文件 `HaveObstacle`（`:731-750`）同形状（`if (c != Controller)`）⇒ 带骨碰撞体的单位"永远有障碍"（机甲 `AllowJumpCount=0` 所以没暴露）。
- **修法**：两处都加 `if (c.transform == transform || c.transform.IsChildOf(transform)) continue;`（与同文件 `GroundCheck:325` 已用的 `IsChildOf` 口径一致）。**没有**动 `_autoEscapeFromOverlap` 开关、没有动预制体——真正的脱困（被外来物压住）仍生效。
- **取证手段（可复用）**：① Console 筛 `自动挣脱` 直接看到瞬移落点；② `execute_code` 里**复算 `OverlapCapsuleNonAlloc`** 并打印每个命中的 `isSelfChild/isCC/layer/path` —— 这一步直接把"和谁重叠"钉死，比读代码快得多；③ 运行时反射把 `_autoEscapeFromOverlap` 置 false，采样确认"上升次数=0"（开关一关就不飘，反向证明因果）。
- **验证**：`offline_compile 06_Gameplay` **0 error** → `refresh_unity(force,all,request)`（**必然退出 Play**，属预期）→ Console `types=[error]` **0 条** + `06_Gameplay.dll` mtime **23:39:32**（前进）。⏳ 待用户重进 Play 复验（预期：机甲落地后静止，不再有 `自动挣脱` 告警）。
- ⚠ **教训**：这类"每帧都跑的物理自愈逻辑"崩的往往不是主流程，而是**它自己的排除条件**；`Overlap*/Cast*` 系列一律要显式排除**自身与全部子物体**（机甲/玩家的骨碰撞体必然在自己的胶囊里）。
