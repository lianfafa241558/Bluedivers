## 咨询：让网友提前内测，是否必须用内网穿透（只读调研，未改代码）

- **核心结论**：不是必须；而且**常用的免费"内网穿透"（ngrok / 花生壳 / cpolar 免费版）对本项目基本无效** —— 它们只转发 TCP，而联机层是 **UDP**（KCP 主通道 17666/udp + 发现 29800/udp 广播）。自建方案里只有 **frp** 能做 UDP（`type = udp`），但需要一台公网服务器，而且**广播包转不了** ⇒ 玩家只能用刚做好的「手动直连」。
- **推荐次序**：① **虚拟局域网**（ZeroTier / Radmin VPN / Hamachi / 蒲公英）—— 0 成本 0 代码，把对方直接当成同一局域网；⚠ ZeroTier 是 L2（广播**可能**可用，未实测），**Tailscale 是 L3/WireGuard、不转发 255.255.255.255 广播** ⇒ 必须走直连。② 房主有公网 IPv4（找运营商要）或双方有公网 IPv6 ⇒ 端口映射 + 直连，延迟最低。③ frp 中转（云服务器成本 + 流量/延迟吃亏）。④ Steam Playtest（免费 + Valve 中继，但要接 Steamworks SDK 并上架）。
- ⚠ **本项目该层的已知限制（未修）**：`NetHostSvc.StartHost` 固定 `StartAsServer("0.0.0.0", 17666)`（全网卡监听 ⇒ 虚拟网卡也能收，OK）；但 **`ServerListPanel.TryParseDirect` 不支持 IPv6** —— 它用 `s.LastIndexOf(':')` 切端口，`::1` 会被切成 ip=":" / port=1，`[::1]:17666` 虽切得对但 `IPAddress.TryParse("[::1]")` 会失败 ⇒ **走 IPv6 内测前必须先修**（识别方括号 / 多冒号时按括号切）。
- 顺手提议（未做）：房间列表面板显示"本机 IP"，方便房主把地址发给网友。

## ✅ 已落地：IPv6 直连解析 + 面板显示本机 IP（用户点单；代码 + prefab）

- **代码** `10UI/Comp/ServerListPanel.cs`：
  - `TryParseDirect` 重写：支持 `[IPv6]:端口`（剥方括号）；无括号时 **0 个冒号=IPv4 / 1 个=IPv4:端口 / ≥2 个=裸 IPv6**（旧实现"最后一个冒号切端口"会把 `::1` 切成 ip=":"、port=1）。实跑 10+ 组用例全对（含 `[240e:...]:17666`、裸 IPv6、`1.2.3.4:0`、`99999` 等非法值）。
  - 新增 `LocalAddressText()` / `RefreshLocalAddress()`（在 `Open()` 里每次展开刷新）+ 字段 `localIpText`。
  - ⚠ **不能按"有没有网关"过滤网卡**：Radmin VPN / Hamachi 这类点对点虚拟网卡可能**无网关** ⇒ 会整张漏掉。改为"有网关的排前面、其余排后面"，另排除 `169.254.x.x`(APIPA) 与 `fe80::`。实跑输出：`本机 IP：192.168.1.12（WLAN）   IPv6: 240e:3a2:4a3:bdd0:7b38:2825:eefc:db2f`（本机 WLAN 有电信公网 IPv6）。
- **prefab** `Assets/Resources/UI/Wnd/SelectMapWnd.prefab`：`Panel` 下克隆 `Status` 得 `LocalIp`（水平 stretch：offsetMin.x=820 / offsetMax.x=-20 / y=18~42），绑定 `localIpText`。
- ⚠⚠ **踩坑（重要，UI 定位必读）**：用 `execute_code` 设 `RectTransform.anchoredPosition` 再 `PrefabUtility.SaveAsPrefabAsset`，会因**保存/加载时父 rect 不一致而数值漂移** —— `Direct/Join` 设的 `(-745, 50)` 保存后变成 `(-35, 5)`（同父的两个子节点偏移量相同）。**解药 = 直接改 `.prefab` YAML 文本里的 `m_AnchoredPosition`**（改完 `refresh_unity`，复查值稳定）；而 `offsetMin/offsetMax` 写法往返稳定（`LocalIp` 一次就对）。⇒ 以后用 MCP 给 UI 定位，优先 `offsetMin/offsetMax`，或改完 YAML 复核一遍。
- 环境事实（本机）：`以太网` Down（未插网线）、`WLAN` Up（192.168.1.12 + 公网 IPv6 240e:…）、另有 2 个 Down 的 Wi-Fi Direct 虚拟适配器。
