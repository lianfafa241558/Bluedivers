## ✅ 落地：机甲"输入有但走不动"= 假空中 + 空中加速度 0（用户当场复现，已修）

### 实测签名（`MoveWatch`）
- `inp=(0.40,0.05,0.92)`（按键链路正常、非 0）、`game IsGrounded=False`、**`cc.isGrounded=True`**、`ccVel=(0,0,0)`、`flags=Below`、`0.4s 内水平位移 0.000m`、`gapToGround≈0.103`（正好 `skinWidth`）。
- 即 **Unity CC 说"贴在地上"，游戏自己的接地判定说"在空中"** ⇒ 每帧走 `AirMove()`。

### 根因（两个环节必须同时成立）
1. `GroundCheck` 的接地探测：**空中把距离压到 `k_GroundCheckDistanceInAir=0.07`（+0.05 = 0.12m）**，而 CC 天然离地一个 `skinWidth=0.1`（实测 0.103）⇒ **余量仅 1.7cm**；且探测只是**一条竖直线**（`GetCapsuleBottomHemisphere()`），CC 半径 1.3m 会"踩在半径内某凸起上、探测点下方低几厘米" ⇒ 整段漏掉 ⇒ `IsGrounded` 卡 false（平地无视觉障碍也复现）。
2. 机甲 prefab **`AccelerationSpeedInAir = 0`** ⇒ `AirMove()` 里 `accelerate = 0` ⇒ **"水平加速度"与"水平速度向 `MaxSpeedInAir` 收敛"同时失效**（`:597-609`）⇒ 空中零水平控制；`ApplyGravity()`（`:782-785`）无条件加重力 ⇒ `gameVel` 一直 -y 但被 CC 挡住 ⇒ 原地不动。玩家 `AccelerationSpeedInAir` 非 0 ⇒ 同样假空中也能走（与"玩家没事、只机甲卡"完全对应）。

### 修法（`06_Gameplay`，已编译）
- `chosenGroundCheckDistance` **不再分空中/接地**，统一 `Controller.skinWidth + GroundCheckDistance`；删除常量 `k_GroundCheckDistanceInAir`（留注释说明原值 0.07 的坑）。
- 新增**射线兜底**：当胶囊探测"一个候选都没有" + `Controller.isGrounded` + 已过跳跃保护期 ⇒ 从 `GetCapsuleBottomHemisphere()` 向下射线（`skinWidth + GroundCheckDistance + 0.15`），命中面朝上且不超 `slopeLimit` 才算接地（`hasGroundHit=true` 的陡坡分支不受影响 ⇒ 陡坡仍按原样滑落）。
  - 顺带把 `hit` 改名为 `groundHit`（`hit` 与外层 `NavMesh.SamplePosition(out var hit)` 重名 ⇒ CS0136），探测结果提到 `if` 外（CS0103）。

- **未做（备选兜底）**：机甲 prefab `AccelerationSpeedInAir` 0→2（用户可在 Inspector 自行改；根因已修，不再必需）。

- 用户反馈"修完还是这样：**走两步 → 进空中 → 滑一段 → 走不动**"。复算 `GroundCheck` 的那条 `CapsuleCastNonAlloc`：

- 现场（机甲 `Exosuit`，`pos.y≈19.0`，`Lamp` 就在 1.77m 外）：`game IsGrounded=False`、**`cc.isGrounded=True`**、`ccVel=(0,0,0)`、`flags=Below`、**`gameVel=(0,-42.93,0)` 且已累 126 秒**（`_lastGroundedTime` 落后 `Time.time` 126s）⇒ 一直走 `AirMove`；机甲 `AccelerationSpeedInAir=**0**` ⇒ 空中零水平控制、只剩惯性 = **走不动**（用户描述的"走两步→进空中→滑一段→走不动"完全对上）。

- **判据**：① `groundCheck` 有合格候选却 `snapGrounded=false`；② 脚下无外来碰撞体但 CC 沉不下去（`cc.isGrounded=True` + 离地 >skin）；③ `CharacterVelocity.y` 长期单调累积（-42.9）⇒ 就是"向下 Move 恒被挡"。现场验证：**加上 `IgnoreCollision` 后同一帧 `IsGrounded` 立即变 true、`gameVel.y` 从 -42.9 归零**。
