## 修复：远端盟友喊话「有语音、无字幕」

- 现象：联机时远端盟友标记/释放战备，语音能听见，`SubtitleSpecUnit` 不显示文字。
- 根因（`SubtitleWnd.cs:275-282` 旧写法）：`UnitTypeEnum.Friend` 分支用 `RolePrefab` 建字幕时 owner 传的是**盟友自己**
  （`Creat(item.Value, item.Value.gameObject, ...)`），而 `RolePrefab` = `SpecialUnitSubtitle.prefab` = `SubtitleSpecUnit`
  ⇒ `Creat` 里 `SetActive(gameObject, tarActor != owner)` 判成 false，整节点硬关；`GetDistance()` 又拿 owner 当基准 ⇒ 恒≈0
  ⇒ `if (dis<7) scale = Clamp01((dis-3)/4f)` = 0，alpha 恒 0。语音在 `OnActorSpeech` 回调里照播（与节点开关无关）⇒ "听得见、看不见"。
- 改法：Friend 分支 owner 改成 `ActorsManager.Player`（观察者口径，与 SpecUnit 分支一致）。离线编译 10_UI 0 error。
- 遗留口径（未改，等老师拍板）：
  ① `SubtitleSpecUnit.Update` 的近距离淡出 `<7m` 会把说话中的字幕压到 0（字号要看得见就该压过去）；
  ② 设置"显示物体标记"= 只在蹲下时，`targetState=false` ⇒ 喊话也不显示（`SubTitleShout` 是忽略该开关、`SubtitleNPC` 是说话时 SetAlpha(1)）。
- 备注：prefab→脚本映射 Shout=SubTitleShout / Mark=SubtitleMark / SpecUnit=Role=SubtitleSpecUnit / NPC=SubtitleNPC
  （`Assets/Resources/UI/Wnd/SubtitleWnd.prefab` 的 5 个字段）。

## 三连修（NPC 对话同步 / RocketBag 朝向 / 天气相位）

1. **NPC 对话不同步**：根因是 **4036 家具桥只在 WaveManager 里 Install**（战斗场景），而 `Furniture_NPCChat` 只出现在
   `Assets/Scene/Utnapishitim.unity`（**舰桥**）⇒ 舰桥阶段家具交互压根没有通道。改法：
   `NetFurnitureBridge` 加 `[RuntimeInitializeOnLoadMethod(AfterSceneLoad)] Bootstrap()` 常驻安装；
   `WaveManager` 里的 Install/Uninstall 两行删掉（⚠ 留着 Uninstall 反而会在打完一局回舰桥时把桥摘掉）。
   舰桥里只有 `Furniture_NPCChat` / `Furniture_Door` / `Furniture_General` 三类家具，影响面可控。
   ⚠ 仍未同步：`Furniture_NPCChat.TryAutoChat`（自动搭话）不走 Operate ⇒ 纯本地触发；交互（按 E）才走 4036。
2. **RocketBag 朝向错**：`LookTarget.target` 指向预制件内的 `Target` 子物体，该子物体挂 `CameraLookCenter`，
   原来每帧写 `FpsHelper.PlayerCameraLookPoint`（语义 = **本机玩家**准心）⇒ 装到盟友身上也朝"我"。
   改为按父链 `GetComponentInParent<IActor>()` 取所有者，走 `FpsHelper.TryGetAimPoint`（本机=相机射线 / 盟友=已同步 yaw+pitch），
   取不到（还没装上的空投箱）才回退原口径。装配父链由 `BagBase.OnInstall` 到 `PlayerMountPoint.BackPoint` 建立。
3. **天气"静态同步"**：类型层面两端只取决于 `TaskState.Seed` + `mapCfg.WeatherInfos`（`SeedStream.Weather=14` 派生流，已是正确口径）；
   真正没同步的是**周期风暴相位**：`WeatherSystem.TickStorm` 原来各端 `_stormTimer += deltaTime` 从自己创建时刻起算
   ⇒ 加载快慢几秒 ⇒ 一边风暴一边平静。改为墙钟相位、锚点取 `IsStartBattle`（4042 同时刻置位）那一刻。
   验证类型是否相同：`NetSyncLog.Load=true` 才有 `[加载/初始化] 本局天气: X（权威种子 Y）` 这行（`LoadLog` 默认关）。

## 再两件：ArmamentItem 滚轮 / GuardDog 炮塔 NRE

1. **赛备面板空白处滚轮无反应**：`ArmamentItem.prefab` 的两个 `ScrollRect`（`AirdropView`，红/绿列表）同物体上只有
   RT+ScrollRect+CanvasGroup，`Viewport` 只有 RT+**RectMask2D** ⇒ 空白处**没有任何 Graphic 命中**，
   `IScrollHandler` 收不到（滚轮靠 EventSystem 射线命中再向上冒泡；命中 button 的内部 Image 才能到 ScrollRect）。
   修法（MCP `execute_code` + `PrefabUtility.LoadPrefabContents`）：给两个 `AirdropView` 各加一张
   `Image`（color a=0、raycastTarget=1）当"透明接收层"。⚠ 不能加在 AirdropView 的**父级**（冒泡只向上）。
   副作用：空白处现在也能拖动列表。`m_CullTransparentMesh`/alpha=0 不影响 Raycast（GraphicRaycaster 只看 rect+raycastTarget）。
2. **GuardDog 炮塔开火 NRE（ProjectilePlayerStandard._OnShoot）**：`WeaponBaseController.Owner` 是**属性**（不序列化），
   只有 `EnemyController:512` / `WeaponBag` / `VehicleWeaponsManager` 赋值；AI 炮塔走 `Turret.Init` 从没设过 ⇒
   `ProjectileBase.Owner = null` ⇒ `Owner.GetComponent<PlayerWeaponsManager>()` NRE（IL2CPP 把栈归到 `_OnShoot` 开头）。
   修法：`Turret.Init(Transform root)` 里 `if (weapon && weapon.Owner == null && root) weapon.Owner = root.gameObject;`
   （显式赋值的不覆盖）+ `ProjectilePlayerStandard._OnShoot` 在 `base._OnShoot()` 之后加 `if (!Owner) return;`
   （玩家子弹被炮塔复用时本就不该做第一人称轨迹矫正）。顺带修好"狗打的伤害 origin/caused 为空"。
   06_Gameplay 离线编译 0 error。

## CampData_SO 检视器：模板/巡逻队自绘 + 任务行跳转

   档位内联 `unitWeights`（预制体·权重·占据补给三列），巡逻队名用**下拉**（只列本阵营已定义的 name）防手写串错。
   摘要把坑标橙：权重合计 0、巡逻队名未定义/未选、重名（WaveManager 只取 FirstOrDefault）、巡逻队没被任何模板引用。
2. 任务行（mainTypes/extraTypes/nestTypes）名称文字可单击 ⇒ `Selection.activeObject + PingObject` 在 Project 选中该
   `MissionData_SO`。⚠ 命中区**只取文字宽度**：本帧先画文字后画按钮，重到按钮区会在按钮消费事件前误触发。
   `RowStyle` 按文字色缓存 GUIStyle（基类 `RowLabel` 每帧 new GUIStyle）；`DimStyle` 关掉 wordWrap（父类灰字样式会溢出行高）。
3. 折叠态存 `SerializedProperty.isExpanded`（不落盘、跨帧稳定），删元素后 `i--` 回退索引用 `bool 返回值`。
   ProjectEditors 离线编译 0 error。
4. ⚠ **IMGUI 布局坑（用户截图报"不少输入框炸了"）**：`EditorGUILayout.PropertyField(p, label, GUILayout.Width(W))`
   里 `W < EditorGUIUtility.labelWidth(150)` 时字段宽 = W - 标签宽 ⇒ **被压成 0/负**，表现是枚举下拉空白、
   int 输入框只剩边框、或整行溢出面板（面板越窄越炸）。修法：`GetControlRect` 拿整行 Rect 后**手工切列**，
   用 `EditorGUI.PropertyField(rect, prop, GUIContent.none)` 让控件吃满 rect；列宽按 `Mathf.Clamp(剩余比例, min, max)` 算，
   右侧固定按钮先占位（`rect.xMax - n*MiniBtnW`）。同坑：长说明文字要放**独立一行**（`s_greyMiniStyle` 会 wordWrap），
   别和按钮挤同一个 Horizontal + FlexibleSpace（面板窄时按钮被挤掉）。RowH=18 / MiniBtnW=20 常量已就位。
