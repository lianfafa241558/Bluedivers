## 定案（2026-10-25 用户实测：Hellbomb 炸死周围人、10m 内塔毫发无损）
- 结论：**不是 bug 漏判，是 3D 距离衰减 + 塔唯一伤害体在塔顶**。Hellbomb `ExplosionRange=20` 是**三维**半径，而塔的 `Detector` capsule 最低点离地约 17m（地形 23.21 / capsule 40.17~56.17）。
- 算给他看：爆心贴地、水平 10m ⇒ 到 capsule 最近点 `sqrt(10²+16.97²)=19.7m` ⇒ 衰减 `(20-19.7)/(20-10)=0.03` ⇒ `1000×0.03≈30` 伤害，塔血 4248 只掉 0.7%（肉眼就是"毫发无损"）；水平再多 0.3m 或地形低一点 ⇒ 直接 0。
- 对照：普通小怪身体贴地，3D 距离≈水平 10m，正好在 `ExplosionInnerRange=10` 边界 ⇒ **满伤 1000** ⇒ 必死。所以"周围人都死了、塔没事"是同一个公式的两种结果。
- ⇒ 等效"有效水平覆盖"对塔顶只有 `sqrt(20²-17²)≈10.5m`，丢在塔脚 10m 外就完全无效。
- 修法（择一，均属**数据/prefab**层）：①给 `DetectorTower` 根（或塔身/底座）加一份 `Damageable`+`Collider`，`Actor.Damageables` 会自动收集，爆炸按"离爆心最近的肢体"结算 ⇒ 塔脚得满伤（**推荐**）；②把现有 `Detector` 的 CapsuleCollider 往下拉到底座（`center.y` 下移、`height` 拉长）使 `ClosestPointOnBounds` 贴地；③顺带把 `HealthEnemy.MainPart` 指向主体 Damageable（现在为 null，`Actor.MainDamageable` 也是 null，联机落点会退化成"第一个肢体"）。
- ⚠ 不要为此改爆炸距离口径（把 3D 改成水平）：那会让"地面炸一下打到天上/楼顶的单位"，全局影响面太大。

## 武器「专有属性」全部不显示（2026-10-25 已修）
- 现象：`Strafe.prefab` 的 `m_UniqueAttr`（齐射轮数 3 / 每轮射击 60，`tag: 0`）在参数面板一条都不出现。
- 根因：`AttrInfo(string name, float value, AttrTag flag)`（`WeaponUpgradeController.cs`）里强加 `tag = flag | AttrTag.DefaultHide`；而 `IsHide()` 对 DefaultHide 的判据是 `Value == attr.PrimeValue.RawFloat && ChangeValue == Value` —— 专有属性的 PrimeValue **就是构造时那个 value**，且没有升级项改它 ⇒ 恒成立 ⇒ **恒隐藏**。
- 修法：该构造改成 `tag = flag`（想默认隐藏由策划在 `UniqueAttrData.tag` 里勾 DefaultHide / IsHide）。`ShowText` 开头仍会跳过 `Special && Value==0 && ChangeValue==0` 的项，不会多出空行。
- 副作用：**所有**武器配的 `m_UniqueAttr` 现在都会显示（以前全部不可见），需要隐藏的逐条加 tag。
- 对照：Strafe 的 `showAttr: 00000000 14000000 19000000` = [0(Ammo/储备数量), 20(DirectDamage/直击伤害), 25(DirectAP/穿甲等级)]，所以截图里那三行正常。
