## 修：舰船→新手教程 抛 `MissingReferenceException`（Actor 已销毁）
- 栈：`SubtitleWnd.Update():134` 读 `ActorsManager.Player.transform`。根因不是 SubtitleWnd 本身，而是 **`ActorsManager.Player` 是 `IActor`（接口引用）**：接口上的 `== null` 走引用比较、**吃不掉 Unity 的假 null** ⇒ 玩家被销毁后仍是"僵尸引用"，判空通过才炸 `.transform`。
- `SettingWnd.TryTeach` 走 `AsyncLoadScene("Teach")` 单场景加载 ⇒ 舰船 Player 先销毁、Teach 的 Player 后注册，中间若干帧就是僵尸窗口；正常大厅→战斗路径没有这个空窗所以没暴露。
- 修法（两处，缺一不可）：
  - `ActorsManager.Unregister()`：`ReferenceEquals(Player, actor) ⇒ Player = null`（销毁即摘，根治，所有读者受益）；`Awake()` 里补 `Player = null`（原来只清了 Actors/Players/SpecUnits 三张表）。
  - `SubtitleWnd.Update()`：`ActorsManager.Player == null` → `!ActorsManager.Player.IsValidMono()`（00Core 现成扩展，接口判销毁唯一正确口径），并把 `player` 提成局部变量复用。
- 副作用（正向）：`HpItemBoss.cs:158` / `NetVehicleBridge.cs:142` 这两处原本无效的 `Player == null` 现在真的生效了。⚠ 口径：**凡是 `IActor`/`IEntity` 这类接口引用判空一律用 `IsValidMono()`，禁止 `== null`**。
- 验证：`offline_compile.py 05_UnitCore 10_UI` 都 0 error（⚠ UI 程序集名是 `10_UI` 不是 `10UI`）；BOM OK。

### 续：同一路径的第二处 —— `PlayerWnd.UpdateCross` 在已销毁的 `PlayerController` 上读 transform

### 用户提议"先在 TryTeach 把 GameState 改成 Transition" —— 查证结论：不能在加载前设
- `Utnapishitim.unity` 里有两个 `GameStateController`，第二个绑了 `state: 8（Transition）进入 → TransSceneController.StartLoad / Play / SetTrigger`、退出 → `Lock / set_enabled`。`StartLoad()` = `AsyncLoadScene(BattleScene)` + `BattleManager.Creat(true)` + 转场音效 + DontDestroyOnLoad。

- 可行变体 = 设在**加载回调最前面**（`AsyncLoadScene("Teach", () => { GameRoot.GameState = Transition; BattleManager.Creat(false); })`）：此时舰船已卸载、Controller 已销毁。副作用三条：① `SubtitleWnd.OnActorCreat` 的 `GameState==Bridge ? ### 追加：各场景 `GameStateController` 实际绑了哪些状态（换状态前先查这张表）

### 修：场景任务的 `entitySize` 恒为 0 ⇒ `MissionDestroyActor` 只捞到任务点上那一个 HaloBomb
