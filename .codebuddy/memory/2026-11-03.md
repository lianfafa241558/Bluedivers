- `TickDriver.Count(平铺)=290 == Actor 数`，`ScheduledCount=345 == TickBehaviour 数`；
  **Health 0 个进表**（本局单位身上全无异常积蓄）⇒ 按需注册按预期工作。
- `TickCount` 全部 >0（最大 4941）⇒ 到期堆的节拍仍在走，没有"注册了但不触发"。

  `DirectorUpdateAnimationBegin` 0.85ms；PlayerLoop 11.82ms；CPU 主线程 8.78ms / GPU 3.37ms ⇒ 约 114fps。

## 投影体开销归因（问答，未完成 A/B）

- 机制：阴影 = **多跑一遍 pass**（阴影相机从光源方向看），屏幕外但影子落在屏幕内的物体照画 ⇒
  **GPU 为主**（shadow map 几何 + 填充，本项目 4096²/2 级联/50~70m）；**CPU 为次**（每 caster 一次 shadow pass draw call，体现在 `CullScriptable` 0.83ms 与 `Submit` 2.63ms）。
- 实测趋势：290 单位空场 GPU 3.37ms → 584 单位波次 GPU **8.30ms**；同期 CPU 主线程 8.78 → 14.67ms。
- ⚠ **Sun 与 Moon 两盏方向光都开了 Soft shadow**（URP 只主光投影，另一盏白跑/抢位）⇒ Moon 应设 `LightShadows.None`。
- ⚠ `shadowDistance` 两处不一致：URP Asset **70**、QualitySettings **50**，运行时以 Asset 为准。
- 同场 A/B 脚本（关两盏方向光 shadow → 等 40 帧 → 比 `FrameTimingManager.GetLatestTimings` 的 gpu/cpu）已写好，但用户中途暂停了游戏（`is_paused=true`）⇒ 无帧推进、未出结果；关阴影状态已确认恢复为 Soft。
