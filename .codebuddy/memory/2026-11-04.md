## 修复 `Particle Orbital Velocity curves must all be in the same mode`

- 根因：`Assets/Resources/VFX/AboState/Vfx_AboHacker.prefab` 那个 **enabled 的 VelocityModule** 里 orbitalY 是 `minMaxState: 3`(Two Curves, 0.7~1.5)，orbitalX/Z 却是 `0`(Constant 0) ⇒ Unity 每次 `VelocityModule::Update`（主线程外 job 线程）刷警告。
- 修法：把 orbitalX/Z 一起改成 `minMaxState: 3`（scalar/minScalar/曲线本来就是 0，视觉零变化）。顺手把第三方 `Assets/Art/Nature/RainSnowCloudEffect/Prefabs/PF_RainSplash.prefab` 的**线性** x/y/z 也对齐（x/z=Two Curves、y=Constant 0 ⇒ 那条 "Particle Velocity curves…" 会随雨刷屏），y 曲线和 scalar 全 0，同样无视觉影响。
- 关键判据：`minMaxState` 0=Constant / 1=Curve / 2=TwoConstants / 3=TwoCurves；**三轴必须完全相同**。`radial` 不参与该判定（现代 UI 根本改不到），把它算进去会得到 250+ 假阳性。
- 工具：`.codebuddy/plans/scan_ps_curve_mode.py`（全 Assets 扫 prefab/scene，1125 文件 ~1s；**只读**）；`.codebuddy/plans/fix_orbital_mode2.py`（按行定位、只改 minMaxState 行）。⚠ 首版脚本按"第一个 VelocityModule"改，改到了 disabled 的那个模块 ⇒ **一个 prefab 里有 N 个 PS/N 个 VelocityModule，必须按块内特征（enabled、orbitalY 模式）定位**。
- 复核：复扫 1125 文件 ⇒ 0 处不一致；两个 diff 各 1~2 行，无整文件行尾/BOM 改写。
