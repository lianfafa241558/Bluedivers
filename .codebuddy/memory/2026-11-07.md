## 准星切回第一人称不恢复（bug）

- 现象：第三人称**非瞄准**时按切视角键回第一人称，准星不出现，换枪再换回来才恢复。
- 根因：`10UI/UI/CrosshairManager.RefreshCrosshairVisibility` 的准星显隐靠"换父级"（`transform` = 显示 / `Tool.GetExchangeArea()` = 藏），第一人称分支写的是 `if (!m_Weapons.AimingHideCrosshair) return;`（**什么都不做**）。而第三人称非瞄准是 `hideCrosshair = !aimState` ⇒ 准星被藏到交换区；切回第一人称时该武器大多 `AimingHideCrosshair=false` ⇒ 提前 return，准星一直藏在交换区。换枪能好是因为 `SetAnimGo` 把准星重挂回 `transform`。
- 修复：第一人称分支改成显式求解 `hideCrosshair = aimState && m_Weapons.AimingHideCrosshair;`（去掉提前 return）。凡是"显隐用换父级实现"的地方，都不能用"条件不满足就不动"的写法。

## `Assets/Shader/MaskTexture.shader`（LX/MaskTexture）蒙版黑区改为真丢弃

- 原做法 `col.a *= maskSum` 只是"混合成透明"，片元照样跑（overdraw 在、深度/排序仍参与）；改为 `clip(maskValue - _Cutoff)`（`_Cutoff` 默认 0.001，`Range(0,3)` 因为旧口径是 rgb **求和**不是取均值，别擅自改成 /3 否则混合强度全变）。
- 该 shader 只有一个 Pass 且 `ZWrite Off`，无 ShadowCaster ⇒ 只需在 `frag` 里 clip 一次；**以后若加 ShadowCaster / DepthOnly Pass，必须把同一个 clip 抄进去**，否则阴影和深度会保留黑区。
- 默认 `_SrcBlend=5(SrcAlpha)/_DstBlend=1(One)` = 加法混合，这种档位下 mask 黑区本就加 0 不可见，出现"黑块"通常是材质把 DstBlend 改成了 OneMinusSrcAlpha。
- 追加 `_MultiplyTex`（默认 white）+ `_MultiplyTex_ST`，在 `col` 之后 `col.rgb *= mulTex.rgb`（不动 alpha，要控透明度补 `col.a *= mulTex.a`）。⚠ 其 uv 是 `i.uv * _MultiplyTex_ST`，而 `i.uv` 已含 `_MainTex_ST` ⇒ Tiling 是**相对主贴图的倍数**（与既有 `_AlphaMask` 同口径），不是独立贴图坐标。

## `FpsHelper.DisanceTMPString`：`string + IEnumerable<string>` 打成类型名

- 症状：TMP 上显示 `System.Linq.Enumerable+SelectEnumerableIterator\`2[System.Char,System.String]<sprite=13 tint=1>`。
- 原因：`string.Concat(a + b)` 里 `Select()` 返回 `IEnumerable<string>`，`+` 按 `object + string` 编译 ⇒ 左侧走 `ToString()` 打出类型名；Concat 收到的其实只有一个 `string`。
- 修法：`string.Concat(coll)` 包住整个 Select 结果，单位标签在**外层**再 `+`。教训：`EnumerateXxxIterator` 出现在 UI 文本里 = 某个序列被当 object 拼进字符串。

## 支援武器拾取后自动切枪

- `Furniture_WeaponPickup.Operate()`：`InstallEquip` 之后显式 `wm.SwitchToWeaponIndex(SlotOf(Support), force:true, allowDual:false)`。
