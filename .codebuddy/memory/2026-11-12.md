## 支援武器「弹尽自动丢弃」实现（AutoDeath 第二语义）
- 需求：带 `WeaponFlag.AutoDeath` 的支援武器把子弹打光 ⇒ 自动卸下 → `canOperate=false` → 小地图消失 → 5 秒后销毁。
- 触发点：`WeaponPlayerController_Equip.cs`（分部）新增 `LogicTick` 覆写 + `TryAutoDropWhenExhausted()`：
  `m_EquipOwner != null`（必须被携带）→ `HasFlag(AutoDeath)` → `!InfiniteAmmo/Magazine` → `Exhausted` → `MarkSpent()` 后 `EquipController.UninstallEquip(this)`。
  ⚠ 刻意写在 `WeaponPlayerController` 而不是 `WeaponController`：后者 AutoDeath 是敌人武器「打空自爆」（`WeaponEnemyController.LogicTick`），语义不同。
- 状态收尾：`Furniture_WeaponPickup.MarkSpent()`（`m_Spent` 置位 + `canOperate=false` + `RefreshMapMark` + `Destroy(gameObject,5s)`）。
  三处必须被 `m_Spent` 挡住，否则打完还能再捡/再上图：`ResetForPickup`（OnUninstall 会调）、`OnEnable`（会报 StateOnGround 把枪摆回来）、`OnDisable`（会报 StateTaken 被当成"被拿走"）。
- 联机：4059 新增 `StateSpent=2 / "spent"`（本类局部码，与 `Furniture_Equip` 的 2/3 不冲突，应用端只按本类分支解）。
  对端 `ApplyRemoteState` 收到 → `DetachFromCarrier()` + `MarkSpent()`（两端各一份实例，各删各的）。
  参照既有范式：`WeaponBag.AutoUnload` → `Furniture_Equip.ReportGone`（背包打光消失）是同一套做法。
- 首个受益 prefab：`Assets/Resources/Weapons/Support/ExpendableAT.prefab`（EAT-17，WeaponFlag=4、WeaponTypeEnum=6/Support、弹匣1备弹0）。
- 验证：离线编译无 csproj（工程根没有 .csproj）⇒ 走 MCP 编译，dll 15:48:47 + Console 0 error。

## 新增 `HideByArchiveSetting`（按存档设置项隐藏自己）
- 文件：`Assets/Scripts/10UI/UI/HideByArchiveSetting.cs`（namespace `FPSGame.UI`，`[AddComponentMenu("UI/按存档设置隐藏自己")]`）。
- 逻辑：`Start` 读一次 `ArchivesData_SO.Current.GetSetting(settingKey) > 0` ⇒ `gameObject.SetActive(hideWhenOn ? !on : on)`；
  随后订阅 `GlobalEventBus.OnSettingCange`（用户明确要"改设置即时生效"），`OnDestroy` 成对退订，回调里按键全等过滤。
  ⚠ 它靠 `SetActive(false)` 关自己，物体失活**不会**退订静态事件 ⇒ 还能被设置改回来，别把退订写进显隐逻辑。
  `settingKey` 默认 `隐藏大厅提示UI文本`（Inspector 可改），`hideWhenOn` 默认 true。
- ⚠ 该键当前**不在** `Assets/Resources/GameData/Archive_Default.asset`（已核，含 `git diff`）⇒ 会在 `GetSetting` 报「缺少设置项」并按 0 处理（= 显示）。要用得先在默认设置资产里补这条 Toggle。
- 验证：`offline_compile.py 10_UI` 0 error；BOM 已补、LF 与同目录既有脚本一致。

## 新增 `DetachChildrenOnDisable`（禁用时把子物体脱成世界根）
- 文件：`Assets/Scripts/00Tools/DetachChildrenOnDisable.cs`（`00_Utils` / namespace `FPSGame.Utils` / `[AddComponentMenu("工具/禁用时脱离子物体")]`）。
- 语义：`OnDisable` 遍历 `List<Transform> _targets`，把**每个 transform 的直接子物体** `SetParent(null, true)`（保留世界位姿）。
- 两个坑已写进实现：必须 `true`（`Transform.DetachChildren` 会丢世界坐标）；子物体循环**倒序**（SetParent 让 childCount 递减，正序漏项）。列表项判空跳过（父级没了子物体必然已销毁）。
- 验证：`offline_compile.py 00_Utils` 源 35 / 0 error；BOM 已补、LF 与同目录一致。
- 同族参照：`05_EffectComp/VFXResidue.cs`（OnDestroy 版、直接子物体、不带 worldPositionStays）。
