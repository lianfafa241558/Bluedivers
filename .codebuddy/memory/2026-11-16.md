## CanvasController 开场淡入被设置窗打断后 HUD 永久隐形（已修）
- 现象：开局 3.5 秒内 ESC 开设置再关，HUD alpha 再也不会回到 1。
- 根因：`_OnGameStart` 协程跑在 HUD 自己的 GameObject 上，`OnWindowStateChange(UI)` 里
  `SetActive(transform,false)` 会**直接停掉该 GameObject 上的协程**，`inIEnumerator` 卡在 true
  ⇒ 关窗回 Game 时 `if (!inIEnumerator ...)` 跳过淡入，alpha 停在 0。
- 修法（`Assets/Scripts/10UI/UI/CanvasController.cs`）：加 `_introRoutine` 句柄 + `AbortIntro()`，
  在 UI 分支里**赶在 SetActive(false) 之前**收尾（StopCoroutine + 复位标志 + alpha=1）；`OnGameStart`
  重入前先停旧序列；淡入 tween 收尾改走 `RevealAfterFade()`，用 `_hiddenByUi` 挡住
  "补间挂在 GameRoot 的 viewTimer 上、HUD 停用后照样跑完把 HUD 重新激活叠在设置界面上"。
- 同类陷阱：`viewTimer`（GameRoot）上的 tween **不会**随 HUD 停用而停；MonoBehaviour 协程会。
- 验证：`10_UI.dll` 14:42:55 重编 + Console 0 error。⚠ 本工程**没有生成 .csproj**（根目录 0 个）
  ⇒ `plans/offline_compile.py` 跑不了，只能走 Unity 重编取证。

## BridgeWnd 舰桥换任务后任务面板不更新（已修）
- 现象：选完任务面板显示了；再换一个任务，面板还是上一份，进战备/重开才变。
- 根因：面板刷新只挂在**场景状态表**（`GameStateController` 订阅 `GlobalEventBus.OnGameStateChange`，
  state 4 进入时调 `BridgeWnd.DisplayTask`）——而 `GameRoot.GameState` setter **旧值==新值不广播**，
  已经 Ready 时再 `SetTask` 不会再进一次 Ready ⇒ 没人再调 DisplayTask；`_shownTaskKey` 只防重复、不是刷新源。
- 修法：`GlobalEventBus` 加 `OnTaskChanged`，`TaskManager.SetTask` 末尾（`SyncTaskState` 之后）发布；
  `BridgeWnd` 在 ShowWnd/HideWnd 里订阅/退订，`OnTaskChanged` → `DisplayTask()`（`!State` 时只清
  `_shownTaskKey`，别让 Animator 打在未激活物体上 + 占掉标记）。
- 顺手：`_shownTaskKey` 补进 `ExtraDifficulty`（同图同名同难度、只有额外难度变时也会刷）。
- 验证：`offline_compile.py 06_Gameplay 09_Managers 10_UI` 0 error（注意 asmdef 名是 `06_Gameplay` 这类带下划线的）。

## 飞扑"瞬移"根因：基类 Duration 是 int 整秒 + 1 秒一拍（已改成自管 `_flyTime`）
- 现象：单位填"技能持续=2"仍"毫无前兆直接出现在目标点"，看不到飞扑弧线。
- 根因（读码+算时间线，非猜测）：`TickBehaviour.TickTime = 1`（`00Core/Timer/TickBehaviour.cs:14`）⇒ `UnitSkill_Base.Tick()` 每拍扣 `nowDurationTime -= 1`，**归零就回调 `SkillEnd()`**；
  而 `UnitSkill_Pounce.SkillEnd()` 是 `StopFlyRoutine() + LandAndRestoreAgent()`，后者第一句 `transform.position = _landPos` = 硬瞬移。
  ⇒ 实际飞行 = `Duration - 1 拍`：Duration=2 只飞 1 秒（正好飞到拱高顶点 4m）就被拽到落点；Duration=1 同一拍归零 = **0 秒纯瞬移**。基类如 `Duration: 0` 更直接。
- 修法（用户拍板 A 案，`UnitSkill_Pounce.cs`）：新增 `[SerializeField] float _flyTime = 2f`（「飞扑时长(秒)」，浮点、与基类"技能持续"脱钩）；
  `SkillStart()` **最前面** `nowDurationTime = 0f` 关掉基类倒计时（必须写在 `_flying` 早退之前：基类是在 SkillStart 返回后才判 `nowDurationTime`，且 `CanExecute` 每拍会把 Duration 重新填回去）；
  `StartCoroutine(FlyRoutine(..., _flyTime))`；**删掉 `SkillEnd()` 重写**（基类不会再调它，留着就是留着那条半空硬切）；飞行收尾只剩协程自然落地 / `OnDeath` / `OnDisable`。
- ⚠ 口径：`UnitSkill_Pounce` 从此不用基类 `Duration`（预制体上那格填什么都不影响飞扑）；冷却仍在起跳那一刻开始计（`ResetCool()` 在 SkillStart 之前）。
- 遗留：飞扑**没有任何 Animator 调用**（纯位移插值 + LookRotation）⇒ 即便飞满 2 秒也只是滑行，"动作感/前摇"要另接动画触发器。
- 验证：`offline_compile.py 06_Gameplay` 0 error；BOM + 纯 LF 保持不变；`check_sources.py` 无输出。新增字段未写进 prefab YAML ⇒ 走脚本默认值 2 秒。

### 已实施：Outline 描边距离限制（`02_Rendering/OutlineRendererFeature.cs`，offline_compile 0 error）
- `OutlineSettings` 新增 `maxDistance`（0 = 不限）。`Execute` 里 `maxDistance > 0` 时先 `SuppressFarRenderers()`，
  `DrawRenderers` 放 `try/finally`，画完 `RestoreSuppressed()`。
- 实现口径：**临时把超距渲染器 `forceRenderingOff = true`**，而不是逐个体 DrawRenderer —— 为的是保住 DrawRenderers 的排序/合批。
  代价：每帧遍历一次自维护的 `_renderers`（每 10 秒 `FindObjectsOfType<Renderer>()` 重扫，~970 个，尖峰 ~1ms）。
- ⚠ 坑1：`CullingResults.visibleRenderers` 在 2022.3 **不存在**；`ScriptableRenderContext.DrawRenderer(...)` 也**不存在**
  （只有 CommandBuffer.DrawRenderer）⇒ 想"按距离逐个提交"这条路走不通。
- ⚠ 坑2：`forceRenderingOff` 是全局状态，**原本就为 true 的（区块剔除/隐藏）必须跳过**，否则还原时会把别人的剔除状态抢成 false。
  漏还原 = 这些物体整局不再绘制，所以必须 try/finally。
- ⚠ 坑3：Outline 在 `AfterRenderingOpaques`，此时主 pass 已画完、透明段还没开始 ⇒ 临时静音安全。
- 待验证：设 `maxDistance` 后要 A/B 看 `Render.Mesh` 总数与 `StdRender.ApplyShader` 次数是否真的降。
