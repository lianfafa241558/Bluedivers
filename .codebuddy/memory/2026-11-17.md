## NormalizeMeshNormals 对 FBX 内嵌 mesh 不持久化（Yuuka.prefab 实证）

- `Assets/Editor/Tool/NormalizeMeshNormals.cs` 不改 `mesh.normals`，只把平均法线 xy 写进 **UV3**（`mesh.SetUVs(3, uv)`），消费端唯一一处：`Assets/Shader/ToonLit/Main/ToonLit_Shared.hlsl:257-267` —— 条件为 `#ifdef ToonShaderIsOutline` **且** 材质 `_UseAverNormal != 0`（默认 0），即只影响描边外扩方向，不影响表面光照。
- 根因：prefab 上的 `SkinnedMeshRenderer.sharedMesh` 是 **ModelImporter 生成的 FBX 子资产**，`EditorUtility.SetDirty` + `AssetDatabase.SaveAssets()` 对它**静默无效**（不报错、不写盘），任何一次 reimport / 重启 / 打包都会按 FBX 重建 → UV3 回滚。
- MCP 实测 `Assets/Resources/Prefabs/StudentModle/Yuuka.prefab`（2026-11-17）：4 个 SMR（Yuuka_Ghost_Body1 / _Hand / _Head / _Head(1)）全部 `path=Assets/Art/Modle/Student/Yuuka/Yuuka.fbx`、`isSubAsset=True`、`uv3=EMPTY`；Body 材质 `Yuuka_Ghost_Body._UseAverNormal=1`，EyeMouth 材质无该属性。
- UV3 为空时 shader 里 `UnpackNormalRG(0,0)` 得到 (-1,-1,0) 归一化的固定切向 ⇒ 描边方向错乱，现象表现为"像没处理/更糟"。
- 修复方向（未执行，等用户拍板）：① 首选 `AssetPostprocessor.OnPostprocessModel` 在 FBX 导入时自动写 UV3（不改 prefab 引用，永不回滚；项目目前没有任何 AssetPostprocessor）；② 备选 `Object.Instantiate(mesh)` 复制成独立 `.asset` 并回填 `sharedMesh`（会产生新资产 + 需改 prefab，注意 MCP 存 prefab 回写旧值的坑）。
