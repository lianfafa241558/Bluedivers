## Devastator 左手嫁接（场景实例，已做）
- 事实：`Devastator/model` 的 SMR 只绑 **24 根骨**，止于 `Bip001 L UpperArm`（断左前臂）；但骨架 `bone_root/Bip001` **完整有** `L Forearm → L Hand → Finger0/1/2` 链。`DevastatorHand.fbx` 是同一角色的另一份**全骨架 + 只有 `L_hand` 一块网格**（11 骨，rootBone=`Bip001 L UpperArm`）。
- 两套骨架同名骨骼 local TRS 实测完全一致 ⇒ 按名字重映射 bones，蒙皮零偏差。
- 做法（MCP 直接在场景里建）：`Devastator` 下新建空 `L_hand`（与 `model` 同级、TRS 归零）→ 加 SMR，复制 mesh/materials/localBounds/quality/shadow/probe 设置 → `bones` 11 根按名字映射到 Devastator 骨架、`rootBone=Bip001 L UpperArm`。
- 校验：新 SMR `bounds` center=(-0.73,0.80,0.06) size=(0.38,0.92,0.47)，与原手**完全相同**。
- ⚠ 坑：把 `DevastatorHand/L_hand` 直接拖过去不行——SMR.bones 仍指向 hand 那套骨骼实例，动画一播手就飞。`DevastatorHand` 根现只剩一个冗余 SMR（无 Collider/Animator），可禁用/删。
- ⏳ 未固化：`L_hand` 是 FBX 实例下的场景新增对象，不在 prefab 里；要落地需 Unpack 后另存，或运行时代码装配，或美术重导带手的 fbx。

## 新工具 `SkinnedBoneRemapper`（骨骼按名称重映射）
- 文件 `Assets/Editor/SkinnedBoneRemapper.cs`（`ProjectEditors` 程序集，ns `FPSGame.EditorExt`）；菜单 = **Inspector 里 SMR 组件标题右键 → 重新映射骨骼(按名称)**（`[MenuItem("CONTEXT/SkinnedMeshRenderer/...")]`，天然只对 SMR 出现）。
- 用法约定：**先把 rootBone 换成新骨架里的骨骼**，工具以它为锚，向上扩到「刚好覆盖全部 bones 名字的最小层」当搜索域（覆盖数不再增长即停，避免爬到场景根串到别的角色），再按名字重写 `bones[]`。不动 `rootBone` / `bindposes`。
- 有 `Undo.RecordObject` + `PrefabUtility.RecordPrefabInstancePropertyModifications`；日志给搜索域路径 + `改指向数/总数`，同名骨骼 warning、找不到 error、没变化 warning。
- 实测（Devastator `L_hand` 往返）：rootBone 指 hand 骨架 → 11/11 全指 hand；改回 dev → 11/11 全指 dev；两次 `bounds` 与骨骼世界坐标完全一致。
- ⚠ 骨骼名是 `Bip001 L UpperArm`（**UpperArm 无空格**）、`Bip001 L Forearm`、`Bip001 L Hand`，别写成 "Upper Arm" 导致 Find 返回 null。
- ⚠ 编译坑复现：写完新 .cs 后 `refresh_unity(mode=force,compile=request)` 返回 `refresh_triggered:false`、dll mtime 不动 ⇒ 需先 `AssetDatabase.ImportAsset(...ForceUpdate)` 生成 meta，再 `CompilationPipeline.RequestScriptCompilation()`，约 10s 后 dll 才更新。

## CampData_SO 检视器：波次「档位」卡右键复制/粘贴
- `Assets/Editor/CampData_SOEditor.cs` 的 `TierCfg` 是手工切列自绘的 helpBox 卡，拿不到 Unity 默认数组的元素右键菜单 ⇒ 在 `DrawTierCfg` 末尾按 `EventType.ContextClick` + `GUILayoutUtility.GetLastRect()`（VerticalScope 结束后取到的就是整张卡的 rect）补右键菜单：**复制该档 / 粘贴覆盖该档 / 粘贴为新档 / 删除该档**。
- 剪贴板方案：`EditorGUIUtility.systemCopyBuffer` + `JsonUtility.ToJson(TierClip)`。快照只存 `tier/weight + unitPaths(GUID→AssetDatabase.GetAssetPath)/unitWeights/unitSizes`，预制体不存实例引用（域重载会失效），粘贴时 `LoadAssetAtPath` 重挂 ⇒ 跨域重载、跨窗口、跨阵营、跨 CampData_SO 资产都能粘。
- 「能否粘贴」= `ReadTierClip()` 试解析 systemCopyBuffer（不可控输入，try 兜 `JsonUtility` 异常，非 JSON 静默返回 null 用于置灰菜单项）。
- ⚠ 菜单回调在 `OnInspectorGUI` 之外执行，基类 `ApplyDirty()` 抓不到 ⇒ 回调里必须自己 `ApplyModifiedProperties + SetDirty + ScheduleSave()`。
- ⚠ 原来 `units.arraySize == 0` 时 `return false` 早退会跳过右键判定，已改成只画提示不早退。
- 注意右键只在卡片空白/标签区生效：压在「预制体」ObjectField 或枚举下拉上会被控件自己的右键菜单吃掉。
- 模板级同理（`DrawTemplateItem` 头行 `row` 右键，排除 `nameRect`/`delRect`）：**复制整个模板 / 粘贴覆盖该模板 / 粘贴为新模板 / 删除该模板**；`TemplateClip{kind,name,tiers:TierClip[],patrolKeys,patrolValues}`。读写档位抽成 `ReadTier/WriteTier` 供档位与模板共用。
- ⚠ 档位与模板共用一个系统剪贴板 ⇒ 两个快照类都带 `kind` 字段（"tier"/"template"），`ReadXxxClip()` 靠它判格式，否则用错结构也能反序列化成功、菜单项会误亮。
