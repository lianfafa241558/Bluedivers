## 肢体拆毁值（Damageable.demolishValue）+ 数据迁移工具

- `Damageable` 新增 `[SerializeField] int demolishValue = -1`（Inspector「拆毁值」）。判据 `> 0`（-1/0 = 未配置）且 `packet.DemolishValue >= demolishValue` ⇒ 复用 `BreakArmor(伤害直接来源)`：**只毁这块肢体**、不结算血量。
- 三个排除条件别删：`!isMain`（主体的拆毁一击必须落到 `Health.demolishValue` 的整只秒杀，否则打身体只毁一块部件、单位活着）、`Health.GetMainPart().IsValid()`（**没配 MainPart 的单位只能靠 Health 秒杀**，抢走这笔会白丢）、relay 转发肢体在方法开头已 return。
- 新增 `_destroyed` 幂等门：`BreakArmor` / `DestroyPart` / `ArmorDestruction` 都只做一次（`PartController` 的腿速惩罚、致死件计数**不是幂等的**，重复派发会扣多次/提前凑满）；`RestoreArmor` 里复位。
- ⚠ 联机限制：`DamageMsg` 不带 `DemolishValue` ⇒ 肢体拆毁只在算出这笔伤害的那端生效（与 `Health.demolishValue` 秒杀同款限制）。
- 迁移工具：`Assets/Editor/HealthDemolishValueSyncTool.cs`（`PrefabBatchToolBase<Health>` 子类，窗口两段式 扫描→应用；另有 `RunAll(bool dryRun)` + 菜单"一键执行"，无对话框、可被 MCP `execute_code` 直接调）。只走 SerializedObject 改 `demolishValue` 一个字段；`-1 与 0 都算"不可拆毁"⇒ 不写`。
