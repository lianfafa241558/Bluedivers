**踩坑**
1. ⚠ `new GameObject(..., typeof(RectTransform))` 的 **sizeDelta 默认 (100,100)**；在 `HorizontalLayoutGroup` 里没有 `LayoutElement` 时会被当成行高，整行被撑到 100+。且 `HLG.childForceExpandHeight=true` + 父级 preferred 会**正反馈放大**（实测 158px）。正解：按钮加 `LayoutElement`（min/pref 28、flexible 0）+ 行内 `HLG.childControlHeight=false`。

4. 10_Effect 看不见 `07_NetGame` ⇒ 成员判定直接复用 `BattleManager.Instance.IsNetMember`（09 已为此暴露）。
5. 单帧步进 = 设 `timeScale = 0.02 / unscaledDeltaTime` 一帧，让 `LogicFrameHost`（scaled delta 累加 50Hz）恰好推进 1 tick，不是渲染帧。
6. 离线编译新文件必须 `--add:<asm>:`，否则 csproj 里没它 → 会误报「`_panel` 不存在」这类假错误。

### 1. H 隐藏时连落点标记一起藏

### ⚠⚠ 新坑：prefab 的 YAML 里**不能写 `#` 注释**

### 4. Shift 存档位 + 相机不再死锁（同日追加）

### 5. 机位过渡受移动速度影响 + 面板滑动条（同日追加）
- `FreeCameraController` 暴露只读 `Speed`（私有 `speed` 字段 1..35，`=`/`-` 调）。
- `DirectorMode`：`ShotBlendTime` 常量拆成 `_blendBase`（面板可调，0.05~1.5s，默认 0.35）+
  `BlendDuration = clamp(_blendBase × ReferenceSpeed(4) / 当前Speed, 0.05, 2)`。
  ⇒ 相机飞得快时跳机位更干脆（speed=20 → 0.07s；speed=1 → 1.4s）。`BlendTo` 在过渡开始时取一次 `duration`，避免中途改速度让进度跳变。

- ⚠⚠ **uGUI `Slider` 被点中后会 Select，并吃掉 `Horizontal` 轴** —— 项目里 A/D 就是 `Horizontal` ⇒ 拖完滑条再按 A/D 走动会顺手改过渡时长（实测确认）。修法双保险：`slider.navigation = new Navigation { mode = Navigation.Mode.None }` + 挂 `EventTrigger.PointerUp` 里 `EventSystem.SetSelectedGameObject(null)`。任何自绘滑动条都该这么做。

### 8. `TMP SubMeshUI [MSYH Atlas Material + fSimpleRound SDF Atlas]` 是什么
面板文本沿用了 `showTime` 的 **MSYH SDF**，而这份字体资产只有 **145 个字符**（图集 1024²、`isMultiAtlasTexturesEnabled=false`、`atlasPopulationMode=Dynamic` 但没跑过 Update Atlas Texture）。探针 42 个面板常用汉字里 **37 个不在 MSYH** 里 ⇒ TMP 回退到 `TMP Settings` 的 **Default Font Asset = `fSimpleRound SDF`**（6705 字，4096²，Static），并为这部分字形在文本对象下自动建一个子物体：
- 名字格式 = `<主材质名> + <回退字体资产名>`，材质是「MSYH 图集 + fSimpleRound 图集」合并出来的 fallback material **实例**；`hideFlags=DontSave` ⇒ **不会写进 prefab**（prefab YAML 里确实没有），TMP 重建时会自己销毁重建，**不要手动删/加**。
- 代价：每个含缺字的文本多 1 个 GameObject + 1 个材质实例 + 1 次 drawcall（面板 21 个文本里 9 个有），且两种字形混排观感不一致。
- 想消掉 = 面板文本换 `fSimpleRound SDF`（与 prefab 里旧 `Text (TMP)` 一致，最省事）；或给 MSYH 补字符 + 扩图集。

### 11. ⚠ 布局组坑：`Child Force Expand Height` 会把自己报成 flexible
症状：`UnitTabs` 明明 `LayoutElement.preferredHeight=22`，却被撑到 **133px**，里面的 tab 也跟着 133。
原因：`HorizontalLayoutGroup.childForceExpandHeight = true` 时，LayoutGroup 的 `ILayoutElement.flexibleHeight` 会返回 **≥1**；`LayoutUtility.GetFlexibleHeight` 取各组件最大值，于是它盖过 `LayoutElement` 的 -1(0)，外层 `VerticalLayoutGroup` 把它当成可拉伸行，和两个 `flexibleHeight=1` 的滚动列表三等分剩余高度（面板 1040 高时正好各 +111）。
修法（双保险）：① HLG 关掉 `childForceExpandHeight`、保留 `childControlHeight=true`；② 容器 `LayoutElement.flexibleHeight` 显式写 **0**；③ 子项 `LayoutElement` 给 min/pref=22 + `flexibleHeight=0`，并把新 RectTransform 的 `sizeDelta` 钉成 `(0,22)`（默认是 100×100）。
派生结论：**"行高定了却被拉高"优先怀疑某个 LayoutGroup 的 Force Expand，而不是 LayoutElement 没写**；反之 `childControlHeight=true` 的容器里，子项**必须**有 LayoutElement，否则行高塌成 0（用户调试时把 `CreateTab` 里的 LayoutElement 注释掉了，已恢复并在代码里写明别删）。

### 12. 导演面板只在 `GameState == Game` 时开（同日追加）

### 13. 固定机位为什么只有 WASD 能用（用户提问，2026-11-26）
`InputManager.prefab` 的输入表是**按窗口分段**存的（`WindowStateEnum`：All=0/Game=1/UI=2/Airdrop=3/FreeCamera=4），`InputManagerBase.Find` 只查 `inputDic[All]` 再查 `inputDic[当前窗口段]`，查不到就**静默 false**（`TryGetValue`，不报错）。实测 45 条绑定里，**FreeCamera 段只有 8 条**：
`H / J / Fire(鼠标左右键) / Aim / Acceler(=/-) / Deceler / Horizontal(A/D,←→) / Vertical(W/S,↑↓)`。

所以在「固定机位（`UIState.PlayerControl=true`、鼠标锁）下」：
- **能用**：WASD（表里有）、鼠标转视角（`Input.GetAxisRaw` 直读，不过表）、开火/瞄准（表里有 + `CanProcessInput()` 放行）、跳/换弹（`CanProcessInput()` 单闸也放行，但 **R 不在 FreeCamera 段 ⇒ 取不到**）。
- **不能用**两层原因叠加：① 键不在 FreeCamera 段（Throw=G、Reload=R、Equip=X、Mule=V、MiniMap=M、Perspective=Y、UseBag=T、Crouching=C 全在 Game 段）；② 代码用 `CanProcessInput(WindowStateEnum.Game)` 或 `(Game, Game)` 的写法在自由相机窗口下**恒 false**（滚轮换武器 `GetSwitchWeaponInput` 就是这条；数字键换武器更狠，`Game+Game` 双闸，且 1-9 本来就留给导演机位）。
- 想放行：① 给 `InputManager.prefab` 的 `window: 4` 段补绑（⚠ prefab YAML 不能写 `#` 注释，会吞后面的列表项）；② 把对应方法的 `CanProcessInput(WindowStateEnum.Game)` 换成"Game 或（FreeCamera 且 `PlayerControl`）"的口径。**数字键 1-9 / Tab / F / J / Alt 不要放**，那是导演自己的键位。
